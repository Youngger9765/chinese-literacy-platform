# 線上 TTS 快取是用哪個發音修正表指紋熱的（#2742）。
#
# 為什麼要記這個：cache key 是 sha256(指紋 + 文字)，所以改一條發音修正
# 就讓**全庫**音檔不可達 —— 不是壞掉，是永遠不會被命中。
# 學生每按一次播放都現場合成（實測 8–24 秒，偶發 503），而 CI 綠、部署成功、沒有告警。
#
# 什麼時候改這個檔：**只有在真的重新預熱過之後**。
#   1. python scripts/prewarm_tts_cache.py --base <有 Azure key 的環境>
#   2. 才把新指紋寫到第一行
#
# ⛔ 不要為了讓 specs/test_tts_cache_fingerprint_spec.py 變綠而先改這裡 ——
#    那是把警報消音，學生照樣每次等 8 秒，而且不會再有人發現。
#
