# 教師面板 · 人工驗證交辦單

> 🤖 由 Claude AI 整理（非 Young 本人）· 2026-10-11
> 交辦對象：Hans　｜　環境：staging（`https://lingoleap-staging.web.app`）
> 每一項請打勾 ✅ 或打叉 ❌；❌ 請在「發現的問題」寫下看到什麼、在哪一步，能附截圖最好。

## 0. 要驗什麼（30 秒版）

教師面板依現場老師的回饋改版，並照均一的順序重做「建班 → 加學生 → 派作業 → 看進度」。
自動化測試已經跑過，**這份是要真人照老師的用法走一遍**，看順不順、看不看得懂、手機能不能用。

本次範圍：A～F 節（已在 staging）。G 節是之後才會上 staging 的功能，先不用測。

## 1. 怎麼登入（不需要帳號密碼）

打開 `https://lingoleap-staging.web.app/login`，按一鍵登入按鈕 **「教師 李老師」**。
要驗學生端時（E 節），用 B 節列印出來的學生帳號登入。

⚠️ 請用**手機（或瀏覽器縮成手機寬度）**也走一次 A～D，結果記在 F 節。

---

## A. 建立班級

| # | 步驟 | 預期結果 | ✅/❌ |
|---|---|---|---|
| A1 | 進「班級管理」，按「建立新班級」，輸入「Hans 驗證班」，按建立 | **直接進到這個新班級**（不是回到班級列表） | |
| A2 | 看班級頁上方 | 班名、班級代碼、學生人數都看得到 | |
| A3 | 因為班上還沒有學生，看學生名單區 | 名單**自動展開**，看到「加學生：學生有沒有帳號？」 | |

## B. 加學生、列印帳密卡

| # | 步驟 | 預期結果 | ✅/❌ |
|---|---|---|---|
| B1 | 選「還沒有帳號」，在框裡貼上三行：`1 王小明`、`2 林雨萱`、`3 陳柏宇` | 按鈕顯示「建立 3 個學生帳號」 | |
| B2 | 按下建立 | 出現綠色框「已建立 3 個帳號」，並提醒「帳號密碼只會顯示這一次」；名單出現這 3 人 | |
| B3 | 按「列印帳密卡」 | 開出一頁卡片（每人一張：班級＋座號、姓名、帳號、密碼、登入網址），有列印對話框；**把帳號密碼抄下來，E 節要用** | |
| B4 | 清空框框，只輸入 `2`，按建立 | 再建立 2 個帳號，姓名是「4 號」「5 號」（座號接著往下排，不跟前面重複） | |
| B5 | 再貼一次 `1 重複的人` 建立 | 提示「有 1 位沒有建立成功」（座號 1 重複），其他人不受影響 | |
| B6 | 切到「已經有帳號」 | 大字顯示班級代碼，說明「請學生登入（可用均一帳號）後輸入班級代碼」，下方可輸入學生編號加入 | |
| B7 | 在「還沒有帳號」那頁，看提醒文字 | 有黃色提醒：用均一帳號登入的學生請改選「已經有帳號」，避免多出重複帳號 | |

## C. 派作業

到班級頁的「作業」分頁，展開「建立與管理作業」。

| # | 步驟 | 預期結果 | ✅/❌ |
|---|---|---|---|
| C1 | 選一課，「派給誰」選「全班」，設一個**明天**的期限，建立 | 作業總表多一欄，全班 5 人都是「未開始」 | |
| C2 | 再派一課，「派給誰」選「部分學生」，**一個都不勾**就送出 | 擋下來，提示「至少勾選一位學生」 | |
| C3 | 勾王小明、林雨萱兩人，期限設**昨天**，建立 | 總表多一欄：王小明、林雨萱是紅色「逾期未交」；其他 3 人是「未指派」 | |
| C4 | 如果李老師有兩個以上的班：再派一課，勾「同時派給其他班（全班）」裡的另一班 | 兩個班都各有這份作業（到另一班的作業分頁確認） | |
| C5 | 看總表下方的圖例 | 有「已交／進行中／未開始／逾期未交／未指派」，顏色跟格子一致 | |

## D. 看進度（老師端）

| # | 步驟 | 預期結果 | ✅/❌ |
|---|---|---|---|
| D1 | 看班級頁的分頁列 | 有「今日總覽、作業、學生、早期介入、更多」；手機上顯示短名稱（總覽、作業、學生、關注），不被切掉 | |
| D2 | 點「今日總覽」 | 看到「待交作業（逾期與今天到期）」、「需要關注的學生」、「作業進度（已交／總數）」，依到期日排序，逾期的排最前面 | |
| D3 | 在作業總表點某一份作業的標題 | 看到這份作業的逐大題統計（朗讀、閱讀理解、生字的完成率與正確率）；沒有分項資料時會明白寫出來，不是空白 | |
| D4 | 點某位學生的名字 | 看到這位學生在這份作業的朗讀、理解、生字表現，以及「唸錯的字」 | |
| D5 | 點「學生」分頁，再點一位學生 | 看到他所有作業的狀態與分數；有「← 回學生名單」可以回去 | |
| D6 | 點「早期介入」 | 有風險的學生直接看到「風險因子」和「建議介入方式」（不用再點開）；練習不夠的顯示「資料不足」 | |
| D7 | 班級頁上方的班級切換器，換到另一班 | 換班後停在同一個分頁，內容換成那一班的 | |

## E. 學生端（確認作業真的只派給該派的人）

用 B3 抄下來的帳號，到 `/login` 用帳號密碼登入（第一次登入會要求同意條款、修改密碼，照指示做）。

| # | 步驟 | 預期結果 | ✅/❌ |
|---|---|---|---|
| E1 | 用王小明登入，看作業 | 看得到 C1（全班）和 C3（部分學生）兩份作業 | |
| E2 | 用 4 號登入，看作業 | 只看得到 C1，**看不到 C3** | |
| E3 | 王小明把 C1 做完並交出，再回老師端看作業總表 | C1 王小明那格變成「已交」（有分數就顯示分數）；今日總覽的已交數加 1 | |

## F. 手機（390 寬左右）

把 A～D 用手機或縮窄的瀏覽器再走一次，只看下面幾點：

| # | 檢查 | 預期結果 | ✅/❌ |
|---|---|---|---|
| F1 | 整頁左右滑 | **整頁不會左右晃動**（只有作業總表可以左右滑，並有提示「← 左右滑動看更多作業 →」） | |
| F2 | 班級標題區 | 按鈕換到班名下面，不擠壓班名 | |
| F3 | 學生頁 | 改成一張一張卡片，不是擠成一排的表格 | |
| F4 | 加學生、派作業的表單 | 按鈕夠大、按得到，輸入框不超出畫面 | |

## G. 之後才上 staging（先不用測）

- **匯入均一班級學生**：建立班級時選均一的班，一次建好班級和學生，不重複匯入
- **班級頁改成均一的三個分頁**：班級設定／指派任務／班級數據，加上重設學生密碼、解散班級

上 staging 後會另外補一份交辦單。
