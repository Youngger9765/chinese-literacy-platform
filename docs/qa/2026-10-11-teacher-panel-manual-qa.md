## 0. 要驗什麼（30 秒版）

教師面板依現場老師的回饋改版，並照均一的順序重做「建班 → 加學生 → 派作業 → 看進度」。
自動化測試已經跑過，**這份是要真人照老師的用法走一遍**，看順不順、看不看得懂、手機能不能用。

本次範圍：A～F 節（已在 staging）。G 節是之後才會上 staging 的功能，先不用測。

## 1. 怎麼登入（不需要帳號密碼）

打開 `https://lingoleap-staging.web.app/login`，按一鍵登入按鈕 **「教師 李老師」**。
要驗學生端時（E 節），用 B 節列印出來的學生帳號登入。

⚠️ 請用**手機（或瀏覽器縮成手機寬度）**也走一次 A～D，結果記在 F 節。

## 發現的問題

| 節次＋項次 | 看到什麼 | 截圖 |
|---|---|---|
| E2 | **「部分學生」作業的排除範圍會隨新生加入而失效**（已開 **#3393**，內含根因與建議修法）。重現步驟：①建一個「部分學生」作業只勾選學生 A（如本輪 assignment id=25「正太與小豬」只勾王小明、林雨萱，或新建的 assignment id=28 只勾 QA甲）②之後再用「加學生」新增一位學生 B（不論有沒有被勾進該作業）③用老師端 `GET /api/teacher/classrooms/{id}/assignment-matrix` 或學生 B 自己的 `GET /api/assignments/my` 都能看到學生 B 被自動排進該作業（`state` 從 `not_assigned` 變 `not_started`）。本輪用全新建立的 assignment id=28（建立時只勾 QA甲，QA乙當下確認是 `not_assigned`）驗證：隨後新增的「QA十號」立刻被該作業標成 `not_started`，而他完全沒有被勾選過。影響：老師以為限定某幾位學生的作業，後加入的學生一樣看得到、做得到，等於「部分學生」這個設計形同虛設。未附截圖（純 API 行為，已在上方寫出重現步驟與請求結果） |
| F3 | 390px 手機寬度下「學生」分頁仍是 3 欄表格（學生／已交作業／平均分數），不是文件描述的「一張一張卡片」。沒有造成版面壞掉或超出螢幕，但與預期 UI 不一致，供日後是否要改卡片式參考 |
