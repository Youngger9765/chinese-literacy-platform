# 課文島遊戲設計（G1核心循環／G2規則／G5回饋）
以 G4-L1〈贏得喝采的輸家〉為例，遊戲化學院視角

## 1. 核心循環
探索→遇見→答題→收服→解鎖，五步閉環。遇見＝文字寶寶從課文原句「浮出」，走到那句才出現，不隨機刷怪。答題＝建築關卡形式本身就是攻擊動作（朗讀/填空/選義/結構填表），作答即出招，不是打完才考試。收服＝寶寶身體殘缺，答對一題補一個部件，補滿才算收服——用「補完整」取代丟球，不顯示捕捉機率。解鎖＝收服觸發該建築週邊霧散/斷橋接通，開下一棟，寶寶同時進駐精靈牧場待複習。

## 2. 開場60秒
船入港、燈塔亮，鏡頭從海面拉近全島剪影：十棟建築多半罩霧或斷橋，像一張未畫完的地圖。燈塔口先傳出一句課文朗讀，不給旁白說明。第一個選擇只有兩個：點燈塔「聽這句」或直接上岸走。驚奇點＝島看起來完整卻大半封閉，逼出「這裡藏著什麼」的懸念。

## 3. 一層一層剝開
初始只開燈塔（簡介）＋書卷長廊（讀全文），其餘八棟罩霧/斷橋：讀完全文→開回音劇場、字源道館；答對道館頭目詞→接通工匠作坊；過工匠作坊→地圖塔開；過地圖塔→謎題神殿開；全過→精靈牧場/樹屋/瞭望台開。
已解鎖範圍可自由走動、重複挑戰，但下一棟只認「讀到並答對上一棟」，不可跳關——自由是「範圍內」的自由，不是整座島任意跳。

## 4. 收服條件（不靠猜選項）
龍爭虎鬥：從原句判斷詞義才能出招；捶胸頓足：三情境選出「懊悔」；摸不著頭緒：打字回答文中「誰、為什麼」；目不轉睛：唸完該段落達流暢率門檻；凝聚力：填出重點表「贏得喝采的原因」。收服動作＝「把殘缺的字/句補完整」，答對逐步補上部件，補滿才正式收服——取代丟球與機率顯示。

## 5. 回饋與獎勵
答對：部件接上＋音效＋寶寶反應；答錯：寶寶吐泡泡顯示提示句，再給一次機會；收服：圖鑑新增一頁（字義/例句/出處）；過關：霧散動畫＋提示音。
防止只抓寶不讀書：收服入口只掛對應原句，無跳題道具；圖鑑不排行、不交易；精靈牧場複習答錯會讓寶寶暫時變灰，須回課文重讀才恢復——逼回讀而非憑印象猜。

## 6. 兩大風險與對策
一、收集強過理解：圖鑑無排行榜，進化（目→目不轉睛）只在下一課「再遇到」才觸發，等同間隔重複逼回讀。
二、霧/斷橋讓低年級孩子誤以為卡關=壞掉：霧區邊緣常駐提示「這裡還沒讀到」而非純灰鎖頭，進度地圖隨時可查已解鎖範圍。
