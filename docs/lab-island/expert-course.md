## 2. 核心內涵

孩子帶走的一句話：**輸了比賽，沒有輸了自己**（勝不驕、敗不餒，做自己）

要能指出文本證據（三條都要找得到）：
- 第 4 段「她沒有因為想贏得比賽而選擇保守，她選擇的是做自己」
- 第 4 段「盡力了，不後悔」
- 第 5 段「只要你沒有輸了自己，比賽就會一直持續下去」

標題本身就是矛盾：「輸家」怎麼會「贏得喝采」？這個問題可以當整座島的主線謎題【推】

## 3. 一層一層剝開【推】

1. **登島：聽見她的名字**（廣告歌、知識補給站影片）→ 知道小戴是誰、鷹眼是什麼（先備知識）
2. **讀全文、做記號** → 知道發生了什麼
3. **語詞我最棒** → 讀得懂「龍爭虎鬥、勢均力敵」，看得出比賽有多激烈
4. **念順順** → 用聲音重新讀過高潮段；這時孩子已經懂詞，念得順才有意義
5. **重點表** → 看出結構：主角、主題、背景、經過、結果。這時「輸了」和「贏得尊敬」第一次並排出現
6. **閱讀理解** → 回答標題那個矛盾：為什麼不保守？她最重視什麼？
7. **語詞應用** → 詞語離開本課，放到自己的生活情境
8. **詞語複習** → 11 個詞全部再遇一次，收尾

第 4 層的位置跟學習單順序不同（學習單的念順順在第二段）。學習單把念順順排在前面有它的理由，要不要調換得問教授

## 4. 紅線

- 不能跳過念順順或縮短計時；不提供「念得快就好」的捷徑（例如跳字還照樣算數）
- 文字寶寶一定要在課文原句裡遇到；不能隨機刷出來，也不能只抓寶不讀課文
- 收服要靠答對或念完，不能用道具、金幣、花錢跳過
- 不比收集數量，只比答對率和自己進步了多少
- 獎勵的內容要是字義、典故，不是點數。點數會讓「做自己」這個主題變成「贏才有獎勵」，跟課文的意思相反
- 不要用輸贏做懲罰動畫（例如答錯就「輸掉」寶寶），這跟本課「輸了也不必難過」衝突
- 門檻數字、段落順序、口音算不算對，都是教授的決定，不由遊戲端改
