# 喝采島 —— 課文島劇本與規格（v4）

課文：國語四上第 1 課〈贏得喝采的輸家〉（L0011，story id 20011）
教材原設計：曾世杰、陳淑麗教授（KIST），學習單作者張明珠
來源：expert-course.md（開課學院）、expert-game.md（遊戲化學院）、expert-writing.md（寫作學院）、research-pokemon-learning.md

## 一、這座島的意義

**核心那一句：輸了比賽，沒有輸了自己**

孩子要能從課文找出三條證據（已逐字對過課文）：

- 第 4 段「選擇的是做自己」
- 第 4 段「盡力了，不後悔」
- 第 5 段「只要你沒有輸了自己」

**主線謎題**取自標題本身的矛盾：輸家怎麼會贏得喝采。這個謎題刻在燈塔的銀牌上，貫穿全劇。

## 二、世界觀

- 島名「喝采島」
  - 故事被讀懂的時候，島上會響起掌聲、島會有顏色
  - 這個故事好久沒人讀懂，掌聲被關進六個詞裡，整座島變成灰色
- 嚮導「小翎」
  - 從羽球上掉下來的一根白羽毛，屬於原創角色
  - 每找回一隻文字寶寶，牠就多會說一句話，這就是孩子的進度表
- 戴資穎只透過課文出現，不當遊戲角色
  - 她的話只用課文原句

## 三、開場（6 格，不放說明文字）

1. 夜晚的海，小船靠岸，整座島是灰的
   - 旁白：這座島，本來很吵
2. 燈塔頂掛著一面灰色銀牌
   - 牌子上刻著：輸掉的人，為什麼有人為她拍手？
3. 一根白羽毛飄下來，停在主角肩上
   - 小翎：你……會讀字嗎？
4. 島上六個方向各有一團灰霧在動
   - 小翎：它們是字變的，可是忘了自己是誰
5. 燈塔門打開，裡面是課文第一段
   - 小翎：先找到她的名字，燈就會亮一點
6. 遠處劇場傳來被悶住的歡呼聲
   - 小翎：聽到了嗎？有人在等掌聲回來

開場結束後，第一個選擇只有兩個：「聽這句」或「直接上岸走」。

## 四、三層剝開（三幕）

| 層 | 建築（已解鎖才走得進去） | 揭露什麼 | 推進條件（學習動作） |
|---|---|---|---|
| 表層：發生了什麼 | 港口燈塔 → 書卷長廊 → 回音劇場 | 她是誰；東京奧運金牌賽；全臺觀眾守在電視前 | 讀第 1 段，點出主角名字，燈塔就亮；讀全文後，生詞會發光；在劇場依課文原句的順序重排比賽畫面 |
| 中層：她為什麼這樣選 | 字源館 → 工匠作坊 → 地圖塔 → 謎題神殿 | 她的球風；落後七分時沒有改打保守 | 字源館做詞義；工匠作坊用第 2 段拼出「邊角球」「難以預測」；地圖塔有「安全小路」和「邊角峭壁」兩條路，要從第 4 段找出她選哪條、為什麼；謎題神殿做閱讀理解 5 題 |
| 內層：輸了為什麼還贏得喝采 | 精靈牧場 → 樹屋補給站 → 星空瞭望台 | 只拿銀牌；「盡力了，不後悔」；大家還是為她喝采 | 在牧場複習詞語；在補給站看背景知識（鷹眼系統、比賽影片）；在瞭望台用自己的話回答 |

- **念順順**：設在回音劇場。只唸老師用 ☞ 指定的段落，計時一分鐘，練 3 次
  - 門檻照學習單：低於 190 字是「還要多練」，191～220 字是「不錯」，超過 221 字是「超厲害」
  - 原型先用學習單這組數字；平台及格線用哪一組，要請曾教授決定
- **解鎖規則**：一開始只開燈塔和書卷長廊，其他建築罩著霧或是斷橋
  - 已開放的範圍可以自由走、可以重複挑戰，但不能跳關
  - 霧區邊緣要一直顯示提示「這裡還沒讀到」，不要只放一個鎖頭

## 五、文字寶寶（6 隻）

- **遇見**：寶寶只會在課文原句旁「浮出」，不隨機刷出來
- **收服方式**：寶寶的身體缺了幾塊，答對一題就補上一塊，補滿才算收服
  - 不丟球，也不顯示捕捉機率
- **答錯**：寶寶吐出提示泡泡，可以再試一次
  - 不會失去寶寶，也不扣分。這一點要和「輸了不必難過」一致
- **複習答錯**：寶寶會「睡著」，孩子回課文重讀那一句，牠就醒來
- **圖鑑**：每隻寶寶一頁，放詞義、課文原句和出處
  - 不做排行，也不能交易
- **進化**：要在下一課再遇到同一個詞才會觸發，等於隔一段時間再複習一次

| 寶寶 | 登場台詞 | 收服用的理解動作 |
|---|---|---|
| 龍爭虎鬥 | 吼！我跟對面那隻一樣大聲，誰也不讓誰！ | 從原句判斷詞義，再做一題填空 |
| 勢均力敵 | 左邊一分，右邊一分，再來一分……到底誰會贏？ | 選出它的同義詞「不分上下」 |
| 目不轉睛 | 噓，別叫我，我連眨眼都捨不得 | 在原句裡找到它，再做一題填空 |
| 捶胸頓足 | 咚！咚！差一點點就進了啦！ | 從上下文推出情緒（懊惱） |
| 凝聚力 | 本來大家各玩各的，現在都擠在同一臺電視前 | 判斷詞義，再做一題填空 |
| 摸不著頭緒 | 咦？球去哪了？往左？往右？我搞不清楚了 | 在工匠作坊解出「難以預測」之後收服 |

## 六、建築門口的話

1. 港口燈塔：燈要亮，先叫出她的名字
2. 書卷長廊：每一卷都有一段話，按順序走，別跳
3. 回音劇場：這裡的歡呼和嘆氣，都是同一場比賽
4. 字源館：一個字拆開，裡面藏著它的意思
5. 工匠作坊：要做出那一球，材料就在課文第二段
6. 地圖塔：兩條路都到得了終點，你猜她走哪條
7. 謎題神殿：答案不在題目裡，在她做的事裡
8. 精靈牧場：找回來的字寶寶在這裡休息，記得回來看牠們
9. 樹屋補給站：累了嗎？她落後七分的時候也沒停
10. 星空瞭望台：最後一個問題，要用你自己的話回答

## 七、結局（星空瞭望台）

1. 小翎問：「她輸了。可是全島的人都在拍手。你覺得，他們在為什麼拍手？」
2. 畫面沒有選項，只有一個空白框和麥克風，孩子可以打字也可以用說的（瀏覽器語音輸入）
3. 孩子說完，他的話變成星星，銀牌亮起來，上面原本的問題換成他自己的那句話
4. 說得不完整也會點亮，小翎會接著問：「你從課文哪裡看出來的？」，並把第 4、5 段的三條證據句標出來，讓孩子點一句
5. 遠方出現第二座灰色的島：「那邊，還有一個沒人讀懂的故事」

這裡不打分數，也不呼叫 AI 判斷。

## 八、紅線

- 不能跳過朗讀；不能用道具或付費跳過題目
- 寶寶只能在課文原句旁遇到
- 不比收集數量，不做排行
- 獎勵是字義和典故，不是點數
- 不使用寶可夢的名稱、丟球捕捉、捕捉機率、道館徽章

## 九、要請教授決定的事

1. 念順順要顯示哪組門檻：學習單的 190／220，還是平台及格線（記得是 120，未重查）
2. 層次順序：念順順要不要移到詞義之後，這跟學習單原本的順序不同
3. 閱讀理解 5 題的答案：原型的答案是我們自己填的，正式版要改由後端判分
