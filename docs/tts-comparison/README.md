## 已發現的差異

### 特殊符號處理
原文有 `~~~`（波浪符），三個引擎處理方式不同：

| 引擎 | 處理方式 | 結果 |
|------|---------|------|
| **Chirp3-HD** | 直接念出來 | 會聽到「波浪符波浪符波浪符」的發音 |
| **Gemini 2.5 Flash** | 自動忽略 | 不會念，自然跳過 |
| **Gemini 3.1 Flash** | 自動忽略 | 不會念，自然跳過 |

> 備註：後端 `tts_service.py` 已有 `_clean_for_tts()` 會在生成前過濾 `~~~`，但之前預生成的 2413 句音檔是在加這個 function 之前產生的，所以舊 cache 帶著錯誤發音。重新生成即可解決

### 句子長度限制
| 引擎 | 限制 | 影響 |
|------|------|------|
| **Chirp3-HD** | 單句 ~40 字上限，超過會 400 error | 需要切句再拼接，拼接處語氣不連貫 |
| **Gemini 2.5 Flash** | 無限制 | 整段丟進去，語氣連貫 |
| **Gemini 3.1 Flash** | 無限制 | 整段丟進去，語氣連貫 |

### 即時生成 vs 預生成
| 引擎 | 76 字 | 707 字 | 適合即時？ |
|------|-------|--------|-----------|
| **Chirp3-HD** | 3.3s | 需切句拼接 | 勉強（需切句 overhead） |
| **Gemini 2.5 Flash** | 12.9s | 49.3s | 不適合，必須預生成 |
| **Gemini 3.1 Flash** | 10.7s | 68.1s | 不適合，必須預生成 |
