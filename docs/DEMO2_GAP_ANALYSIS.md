## A. 方大哥期望 vs 現狀 Gap Analysis

以 `docs/PLATFORM_VISION_FANG.md` 及 `docs/langlangshangkou/PRODUCT_INTRO.md` 為基準，逐項比對：

### 六步驟學習流程

| 步驟 | 方大哥期望 | 現狀 | 狀態 |
|------|-----------|------|------|
| **1. 簡介** | 系統介紹作者、文章、背景；可點 Mic 用 TTS 口語說明 | `Intro.tsx` 已實作：顯示作者、背景、TTS 朗讀功能 | ✅ 已完成 |
| **2. 逐段朗讀** | 同音自動修正 + 分級鼓勵（>=80% / >=60% / <60%） | `LiveTutor.tsx` 已實作：`correctHomophones()` 同音修正、三級鼓勵（READING_EXCELLENT/READING_PASS）、隨機鼓勵池、連續正確加碼 | ✅ 已完成 |
| **3. 課文理解** | 蘇格拉底對話（待定） | `ComprehensionChat.tsx` 已實作：Vertex AI Gemini 驅動的 5 題蘇格拉底對話、3 階段提問、circuit breaker | ✅ 已完成（超越期望） |

| 期望 | 現狀 | 狀態 |
|------|------|------|
| **「溫暖但堅定」的蘇格拉底助教** | LiveTutor 有三級鼓勵、連續正確加碼；ComprehensionChat 蘇格拉底對話有 warmup/core/stretch 三階段 | ✅ 已完成 |
| **同音自動修正**（減少學生挫折感） | `pinyin.ts` 的 `correctHomophones()` 已實作，STT 轉錄後自動修正同音異字 | ✅ 已完成 |

## D. 使用者旅程完整性

以一位國小五年級學生的視角，走過完整的 6 步驟學習流程：

### Step 0: 進入平台

```
學生打開瀏覽器 → 看到「AI 朗讀助教」首頁 → 點擊「進入圖書館」
```

- ⚠️ **無登入系統**：任何人都可以直接進入。Demo 展示時無問題，但正式使用需要身份認證。
- ✅ **StoryLibrary 載入**：從後端 API 載入 57 篇課文，有年級篩選、搜尋功能、骨架動畫。

### Step 1: 簡介

```
學生選擇「大自然的線索」→ 看到作者介紹、背景說明
```

- ✅ **正常運作**：顯示作者、背景、TTS 朗讀按鈕。
- ✅ **注音開關**：可切換注音顯示。
- ⚠️ **背景資料品質**：依賴 YAML 中 `intro` 欄位的完整度。部分課文可能 intro 資料不完整。

### Step 2: 逐段朗讀（LiveTutor）

```
學生看到第一段課文 → 點擊麥克風 → 開始朗讀 → 即時看到 STT 轉錄
→ 系統評分（>=80% 過關 / >=60% 稱讚 / <60% 重試）
→ 逐段完成所有段落
```

- ✅ **核心功能正常**：Web Speech API 錄音 + STT + 同音修正 + 三級鼓勵。
- ✅ **DiffDisplay**：逐字比對正確/錯誤/漏讀/多讀，視覺標註清楚。
- ⚠️ **Web Speech API 限制**：
  - 只在 Chrome/Edge 上可靠運作
  - 準確率不如 Azure Speech SDK（尤其兒童發音）
  - Safari/Firefox 不支援
  - 無法保存錄音檔案（無法重聽）
- ⚠️ **缺少段落達標解鎖機制**：PRD 要求「第一段達標後解鎖第二段」，目前未見此邏輯。

### Step 3: 課文理解（ComprehensionChat）

```
AI 提出問題（蘇格拉底式）→ 學生打字回答 → AI 評估理解度 → 5 題完成後結束
```

- ✅ **功能完整**：Gemini 驅動、5 題 3 階段、server-side session。
- ✅ **Session 恢復**：SessionExpiredError 自動重建（Cloud Run 重啟後）。
- ✅ **注音 + 課文顯示**：左側顯示課文（含高亮段落），右側對話。
- ⚠️ **語音輸入**：PRD P1 提到支援語音輸入，目前僅文字輸入。

### Step 4: 生字練習（VocabPractice）

```
顯示朗讀中讀錯的字 → 學生點擊字卡 → 進入筆順練習
```

- ✅ **錯字連動**：從 `attempt.mispronouncedWords` 自動彙整練習字。
- ✅ **注音顯示**：每個字卡有注音標註。
- ✅ **筆順練習**：WriteCharacter 元件，hanzi-writer 驅動。
- ⚠️ **#139 Bug**：未朗讀就進入此步驟時，錯誤顯示「讀得很棒！沒有漏字」。
- ⚠️ **缺少部件拆解**：PRD 要求顯示「清 = 氵 + 青」的部件教學，目前無此功能。
- ⚠️ **缺少字義、例句**：PRD 要求字型、字音、字義、筆順四面向，目前只有字音+筆順。

### Step 5: 全文朗讀（FullReading）

```
學生朗讀全文 → 系統即時轉錄 → 結束後顯示匹配率 + DiffDisplay
```

- ✅ **功能完整**：Web Speech API 全文 STT + fluencyAnalyzer + DiffDisplay。
- ✅ **CPM 計算**：正確字數/分鐘。
- ⚠️ **與逐段朗讀相同的 Web Speech API 限制**。

### Step 6: 報告（AssessmentReport）

```
學生看到完整的六環節診斷報告 → 出場卷選擇題 → 回到圖書館
```

- ✅ **環節一**：朗讀結果總覽（準確度/CPM/全文匹配率）
- ✅ **環節二**：錄音內容與智能分析（STT 轉文字 + 四大分類統計）
- ✅ **環節三**：逐句分析對比（DiffDisplay accordion）
- ✅ **環節四**：錯字詞練習清單（含 TTS 發音按鈕）
- ✅ **環節五**：練習建議（規則式，根據 CPM + accuracy）
- ❌ **環節六**：AI 詳細分析 — 僅 placeholder（灰色卡片 + 「即將推出」）
- ✅ **出場卷**：3 題選擇題，從錯字自動生成
- ⚠️ **無錄音播放**：環節二雖然有 STT 轉文字，但無法重聽錄音
- ⚠️ **無學習歷史**：報告為一次性，重新載入頁面後消失
