> 版本：Beta v1.0 | 更新日期：2026-03-09

## 什麼是 LingoLeap Beta？

LingoLeap 是一款 AI 輔助國語文閱讀學習平台，專為國小高年級至國中生設計。Beta 測試階段邀請您搶先體驗平台功能，協助我們在正式上線前發現問題、收集意見。

**您的參與對我們非常重要。** 每一條回饋都會直接影響最終產品的品質。

## 學習流程介紹（6 步驟）

LingoLeap 的核心學習流程稱為「朗朗上口六環節」：

1. **課文簡介** — AI 提供課文背景與脈絡說明
2. **逐段朗讀指導** — AI 即時聆聽並給予朗讀建議（LiveTutor）
3. **生字練習** — 筆順練習與注音標示
4. **課文理解** — 蘇格拉底式 AI 對話，深化理解
5. **全文朗讀評估** — 完整朗讀並取得診斷報告
6. **學習報告** — 朗讀結果總覽、錯字詞分析、練習建議

## Beta 階段已知限制

以下功能在 Beta 期間尚未完整或有已知問題，請知悉：

| 功能 | 狀態 | 說明 |
|------|------|------|
| 行動裝置支援 | 部分支援 | 手機瀏覽器朗讀功能可能不穩定 |
| 語音朗讀評測 | Beta | 部分口音可能影響辨識準確率 |
| 筆順動畫 | 測試中 | 少數生字筆順資料待補齊 |
| 多班級管理 | 開發中 | 教師目前僅能管理單一班級 |
| 離線模式 | 未支援 | 需保持網路連線 |
| 舊版瀏覽器 | 不支援 | IE 及舊版 Edge 無法使用 |
| Safari 朗讀 | 受限 | 需手動授權麥克風，部分功能受限 |

## 如何回報問題

### 方式一：GitHub Issue（建議）

1. 前往 GitHub Issues 頁面
2. 點選「New Issue」
3. 選擇「Bug Report」範本
4. 填寫以下資訊：
   - **問題描述**：發生了什麼？
   - **重現步驟**：如何觸發這個問題？
   - **預期結果**：您認為應該發生什麼？
   - **實際結果**：實際發生了什麼？
   - **環境資訊**：瀏覽器版本、作業系統
   - **截圖或錄影**（如有）

### 方式二：回饋表單

填寫 `feedback-form.md` 中的問卷，透過 Email 或 Line 傳送給管理員。

### 方式三：直接聯繫

- **Email**：youngtsai@junyiacademy.org
- **Line 群組**：Beta 測試者群組（由管理員邀請加入）

## 測試期間注意事項

1. **資料安全**：請勿在測試環境輸入真實學生個資
2. **帳號使用**：測試帳號僅供 Beta 期間使用
3. **功能回饋**：不論是問題或建議，我們都歡迎
4. **保密義務**：Beta 功能尚未公開，請勿對外分享截圖或功能細節
5. **測試頻率**：建議每週至少使用 2-3 次，方能給予有效回饋
