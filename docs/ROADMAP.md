### Phase 5 — 測試驗收 + Bug 修復 (3/12 ~ 4/6)

> **目標**：確認 Demo 2-4 所有功能都能正常使用，修復所有已知 Bug。

**5.1 人工測試（分角色）**

| 角色 | 測試旅程 | 關鍵驗收點 |
|------|---------|-----------|
| 👨‍🏫 教師 | 註冊→建校→建班→匯入學生→上傳課文→指派作業→查看報表 | 班級熱力圖、學習預警、作業批改 |
| 👨‍🎓 學生 | 登入→選課文→8步驟學習→查看報告→完成作業→看成就 | 朗讀分析、蘇格拉底對話、遊戲化XP |
| 👨‍💼 管理員 | 登入→管理學校→管理教師→查看全校統計 | RBAC 權限、CSV 匯入 |
| 👨‍👩‍👦 家長 | 登入→查看孩子進度→接收通知 | 家長儀表板、學習曲線圖 |
| 🧑‍💻 自學 | 不登入→課文庫→自學模式→完成學習 | 不需帳號即可體驗核心功能 |

**測試流程**：測完在 issue 留言 + 截圖 → 標記 `tested` 或回報 bug → 參考 `docs/TESTING_GUIDE.md`

## 風險管理

| 風險 | 影響 | 緩解 |
|------|------|------|
| Web Speech API 瀏覽器限制 | 僅 Chrome/Edge | 暫時接受，試點學校確認使用 Chrome |
| 實習生經驗不足 | Issue 需多次 review | 每個 issue 附思考方向 + 驗收標準 |
| 試點學校時程延遲 | Beta 數據不足 | 提前 6 月確認學校 + 備案 |
| 暑假期間 Bug | 影響教學 | 24/7 技術待命 + 自動監控告警 |
| 文件與代碼不同步 | 新人 onboard 困難 | 每個 Phase 結束時集中更新文件 |
