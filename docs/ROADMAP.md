| **段落/短文寫作** | ❌ 缺 | 只有造句，缺段落寫作 + AI 批改 |

### 優先處理建議

| 優先級 | Gap | 歸屬 Phase | 說明 |
|--------|-----|-----------|------|
| **P1** | 口說表達（覆述/摘要） | Phase 7 | 學生聽完/讀完 → 用自己的話說一遍，AI 評估覆述完整度 |
| **P1** | 段落聽力理解 | Phase 7 | 升級 ListeningPractice：聽段落 → 回答理解題 |
| **P1** | 閱讀策略引導 | Phase 7 | 在 ComprehensionChat 加入「預測→澄清→摘要」scaffold |
| **P2** | 手寫辨識 | Beta 後 | 需 ML 模型或第三方 API（成本高），Beta 先用鍵盤 |
| **P2** | 聲韻覺識遊戲 | Beta 後 | 低年級適用，目標用戶高年級優先級低 |
| **P2** | 段落寫作 + AI 批改 | Beta 後 | 需強 AI 寫作評估能力，暑假 Beta 範圍太大 |

## 風險管理

| 風險 | 影響 | 緩解 |
|------|------|------|
| **個資法 (PDPA) 合規** | 學生姓名/成績屬個資，違規罰則重 | Phase 6 使用條款 + 隱私政策 + 家長同意書 |
| **學校設備差異** | Chrome 版本低、麥克風不可用、網速慢 | Phase 8 設備檢查 + 離線快取 + 降級方案 |
| **AI 呼叫費用** | Vertex AI 按量計費，50+ 學生可能超支 | 監控 Billing、設定每日上限、快取常見回應 |
| **Young 單點故障** | 唯一掌握全架構的人，生病/忙碌 = 停滯 | 文件化關鍵知識、培訓實習生熟悉後端 |
| Web Speech API 瀏覽器限制 | 僅 Chrome/Edge | 暫時接受，試點學校確認使用 Chrome |
| 實習生經驗不足 | Issue 需多次 review | 每個 issue 附思考方向 + 驗收標準 |
| 試點學校時程延遲 | Beta 數據不足 | **4月起開始聯繫**（不等 Phase 8）+ 備案學校 |
| 暑假期間 Bug | 影響教學 | SLA 回應 < 2 小時 + 自動監控告警 |
| 文件與代碼不同步 | 新人 onboard 困難 | 每個 Phase 結束時集中更新文件 |

## 未來功能藍圖（Beta 後 / 2026 Q4+）

> 以下功能不在 Phase 5-9 範圍內，但根據 BRD/MRD 市場定位 + 教學理論，是中長期必須規劃的。

### RAG 後台 + AI 知識庫

| 功能 | 說明 | 效益 |
|------|------|------|
| **課文 RAG 檢索** | 將 57+ 篇課文 + 生字 + 教學指引向量化，AI 對話時能引用課文內容 | 蘇格拉底對話更精準，能引用原文段落 |
| **教育部字典 RAG** | 教育部國語辭典 + 常用字頻率表向量化 | 生字解釋更權威、更適合學生程度 |
| **教師教學知識庫** | 教學法文件（PEDAGOGY.md 內容）RAG 化，AI 助教能引用教學理論 | AI 回答有教學理論支撐 |
| **錯誤模式庫** | 收集學生常見錯誤（錯字、語法、斷句），建立 pattern → 教學建議 mapping | AI 能說「很多同學也會把X寫成Y，因為…」 |
| **課文難度自動標註** | 用 RAG + 字頻表自動計算課文難度等級 | 不需人工標難度 |

> **技術選型**：Vertex AI Vector Search 或 pgvector（PostgreSQL 內建），Beta 階段課文量小，pgvector 就夠。

### 模擬 Agent（學生/教師練習用）

| Agent | 使用者 | 功能 | 說明 |
|-------|--------|------|------|
| **AI 學伴** | 學生 | 陪伴式學習 | 學生遇到困難時，AI 學伴用同齡語氣鼓勵 + 提示，不直接給答案 |
| **AI 朗讀示範** | 學生 | 範讀 + 跟讀 | AI 先朗讀一遍（TTS），學生跟讀，比對差異 |
| **AI 模擬學生** | 教師 | 教學練習 | 教師可跟 AI 模擬學生互動，練習如何引導閱讀困難的學生 |
| **AI 出題助手** | 教師 | 自動出題 | 給一篇課文，AI 自動生成理解題、造句題、聽寫字表 |
| **AI 差異化建議** | 教師 | 個別化教學 | 根據班級學習數據，AI 建議哪些學生需要額外關注 + 具體教學策略 |

> **「AI 模擬學生」特別有價值**：新手教師可以練習面對不同程度學生（高成就、中等、學習困難），每種模擬學生有不同反應模式。

### 台灣市場擴展功能

#### 學習扶助（PRIORI）整合

> BRD 首要目標：「成為台灣學習扶助計畫官方推薦工具」

| 功能 | 說明 | 對應 BRD/MRD |
|------|------|-------------|
| **PRIORI 評測對接** | 匯入學生 PRIORI 篩選測驗結果，自動設定學習起點 | MRD 2.3: 教育局決策者需求 |
| **學習扶助 80 節課程包** | 暑假學習扶助 80 節課的完整教材包（課文+練習+評量） | BRD 6.1: 暑假試點切入點 |
| **進步追蹤報告** | 符合教育部學習扶助成效報告格式，可直接提交 | 減少教師行政負擔 |
| **低成就學生適性** | 降低認知負荷：更大字體、分段更短、AI 提示更多 | 教學理論：馬太效應早期介入 |

#### 考試題庫 + 素養題

| 功能 | 說明 | 市場價值 |
|------|------|---------|
| **會考國文題庫** | 國中會考國文歷屆考古題，AI 解題 + 策略分析 | 家長/學生最有感的功能 |
| **學測國文題庫** | 高中學測/指考國文考古題 | 擴大用戶年齡層 |
| **素養題訓練** | 108 課綱素養導向題目（長文閱讀+跨領域+生活情境） | 對齊課綱改革方向 |
| **AI 模擬考** | AI 根據學生弱點自動組卷，模擬考試環境 | 考前衝刺用 |

> **注意**：考古題有著作權問題，需確認教育部公開的範圍。會考/學測考古題通常由 CEEC 公布，需確認授權條款。

#### 作文批改

| 功能 | 說明 | 技術 |
|------|------|------|
| **作文 AI 批改** | 學生寫短文/作文，AI 批改內容、結構、用詞、修辭 | Gemini 長文分析 |
| **六級分評分** | 對標會考作文六級分標準，自動評分 + 各維度分析 | 需 fine-tune 或 few-shot prompt |
| **修改建議** | AI 不只標錯，還示範如何改得更好 | RAG 引用範文 |
| **寫作引導** | 看圖寫作、命題作文、讀後感，AI 一步步引導 | Agent workflow |

> **技術挑戰**：中文作文 AI 批改比英文難很多（語意理解、修辭手法、文化背景）。建議先做「造句→短段落→短文」漸進式，不要一步到位做長篇作文。

#### 學堂 / 教師社群

| 功能 | 說明 |
|------|------|
| **教師研習平台** | 線上閱讀科學研習（影片+測驗），完成給研習時數證明 |
| **教學案例分享** | 教師分享如何用 LingoLeap 改善教學的案例 |
| **共備資源庫** | 教師上傳教學設計/學習單，社群共享 |
| **教學顧問諮詢** | 預約閱讀科學教學顧問線上諮詢 |

> **為什麼重要**：MRD 5.2 差異化要素 #1 就是「閱讀科學理論 + 教學顧問驗證」。學堂是把這個優勢規模化的方式。教師用得好 → 推薦給其他教師 → organic growth。

### 第三方平台整合

| 平台 | 功能 | 說明 | 可行性 |
|------|------|------|--------|
| **Google Classroom** | 作業同步 | 教師在 Google Classroom 派作業 → LingoLeap 自動收到 | Google Classroom API (REST)，教育帳號免費用，台灣很多學校已在用 |
| **Google Classroom** | 成績回傳 | LingoLeap 學習成績自動回傳 Google Classroom 成績簿 | Coursework API 支援 |
| **Google Classroom** | 單一登入 | 用 Google Classroom 帳號登入 LingoLeap（已有 OAuth 基礎） | 已有 Google OAuth (#27)，延伸即可 |
| **YouTube** | 範讀影片 | 課文配範讀影片（教師或專業朗讀者），學生跟讀 | YouTube Data API + 嵌入播放 |
| **YouTube** | 教學影片庫 | 連結相關教學影片（部件教學、聲韻覺識） | YouTube 搜尋 API |
| **Google Drive** | 課文匯入 | 從 Google Drive 直接匯入教師的 Word/PDF 課文 | Google Drive API |

> **Google Classroom 整合特別有價值**：台灣學校已大量使用 Google Workspace for Education。如果 LingoLeap 能跟 Google Classroom 無縫整合，教師不用額外管理帳號和作業，大幅降低導入門檻。
>
> **建議時程**：Google Classroom 基礎整合（單一登入 + 班級同步）可考慮在 Phase 8 或 Beta 初期做，作業同步 + 成績回傳 Beta 後做。
