## 關鍵發現

1. **標準9步結構高度一致**：L1-L41 及 L48-L55 的白話文課文全部遵循一→二→三→四→五→六→七→八→九的步驟，差異僅在各步驟內容

2. **文言文完全不同**：G8 的 L42, L43, L46, L47 採用獨立的5步結構(文白比對→文章重點→文言聚光燈→文意測驗)，念順順改為秒計時

3. **多文本是最複雜的結構**：L56-57(2篇)和 L58-60(3篇)各有獨立的閱讀+分析，最後做跨文本比較

4. **策略難度逐年級遞進**：
   - G4：基礎句型+簡單推論
   - G5：人物特質推論+文章結構
   - G6：主旨推論+自我提問+品格力
   - G7：表格整理+PREP表達+媒體素養+思辨
   - G8：文言文閱讀法
   - G9：數據素養+多文本比較+讀者觀點

5. **念順順門檻逐級提升**：G4(190/220) → G5(200/230) → G6(210/240) → G7+(220/250)

6. **L44+L45 和 L56-57 和 L58-60 是成對/成組的課文**，需要連續教學

7. **L55 是唯一標註「策略：無」的課文**，可能作為綜合練習或評量用途
