## 快速開始

LingoLeap 是 AI 輔助的國語文閱讀學習平台，協助教師：

- 追蹤學生朗讀與理解進度
- 指派課文與閱讀任務
- 透過 AI 蘇格拉底對話促進學生思考
- 生成個人化學習報告

**首次使用流程：**

```
登入 → 建立班級 → 邀請學生加入 → 指派課文 → 查看報告
```

---

## 登入與帳號設定

### 登入步驟

1. 開啟 LingoLeap 網站
2. 點選「登入」
3. 輸入學校提供的教師帳號（Email）與密碼
4. 點選「登入」按鈕

### 首次登入

- 系統會要求您閱讀並同意服務條款與隱私政策
- 建議立即修改預設密碼：點選右上角頭像 → 「修改密碼」

### 忘記密碼

1. 在登入頁面點選「忘記密碼」
2. 輸入您的 Email
3. 查收重設密碼郵件（請注意垃圾信件夾）
4. 點選郵件中的連結，設定新密碼

## 建立班級

### 新增班級

1. 登入後進入「教師儀表板」
2. 點選「新增班級」按鈕
3. 填寫班級資訊：
   - **班級名稱**：例如「五年三班」
   - **學年度**：例如「114學年度」
4. 點選「建立」

### 邀請學生加入

建立班級後，系統會產生專屬的**邀請碼**。

**方式一：分享邀請碼**
1. 在班級頁面找到邀請碼（例如：`ABC123`）
2. 將邀請碼告知學生
3. 學生登入後，點選「加入班級」並輸入邀請碼

**方式二：分享 QR Code**
1. 點選「顯示 QR Code」
2. 讓學生用手機掃描 QR Code 直接加入

### 管理多個班級

- 教師儀表板左側會列出所有班級
- 點選班級名稱可切換查看
- 可同時管理多個班級

## 管理學生

### 查看班級名單

1. 進入班級頁面
2. 點選「學生名單」分頁
3. 可看到所有學生的：
   - 姓名與帳號
   - 最近學習時間
   - 完成課數

### 學生標籤系統

教師可為學生新增標籤，方便分組與追蹤：

1. 在學生名單中，點選學生姓名旁的標籤圖示
2. 可選擇或新增標籤（例如：「需要加強」、「表現優異」）
3. 標籤只有教師可見，學生看不到

### 移除學生

1. 在學生名單找到該學生
2. 點選「...」選單
3. 選擇「移出班級」

## 指派課文

### 瀏覽課文庫

1. 在班級頁面點選「指派課文」
2. 瀏覽系統內建的 57 篇課文
3. 可用以下方式篩選：
   - 年級（三～六年級）
   - 類型（記敘文、說明文、古詩）
   - 字數難度

### 指派給班級

1. 選定課文後，點選「指派給班級」
2. 設定截止日期（選填）
3. 點選「確認指派」
4. 學生下次登入即可看到新指派的課文

### 查看指派狀況

- 在班級頁面的「作業」分頁可看到每篇課文的完成率
- 可看到哪些學生已完成、哪些尚未開始

## 查看學習報告

### 班級總覽

在「班級效能熱圖」（Classroom Performance Heatmap）可一眼看出：
- 每位學生在各課文的學習狀況
- 顏色深淺代表學習進度（深綠=完成，淺色=進行中，空白=未開始）

### 個人報告

1. 點選任一學生姓名
2. 查看該學生的詳細學習歷程：
   - **朗讀評分**：AI 評估發音準確度
   - **理解測驗**：蘇格拉底對話的回答品質
   - **生字練習**：筆順練習完成度
   - **學習時間**：每次學習花費的時間

### 六環節診斷報告（朗朗上口）

每位學生完成課文學習後，系統會生成完整的診斷報告：

| 環節 | 說明 |
|------|------|
| 朗讀結果總覽 | 整體評分與星級 |
| 錄音內容與智能分析 | AI 分析朗讀內容 |
| 逐句分析對比 | 學生朗讀 vs. 標準文本 |
| 錯字詞練習清單 | 需要加強的字詞 |
| 練習建議 | 個人化學習建議 |
| AI 詳細分析 | 完整 AI 評估報告 |

## 通知中心

### 查看通知

- 點選頁面右上角的「鈴鐺」圖示
- 紅點代表有未讀通知

### 通知類型

| 通知類型 | 說明 |
|---------|------|
| 學生完成課文 | 學生完成指派的課文學習 |
| 學生加入班級 | 新學生透過邀請碼加入 |
| 系統公告 | 平台更新或重要通知 |

## 常見問題

**Q: 學生說忘記邀請碼，怎麼辦？**
A: 進入班級頁面，邀請碼會顯示在頁面上方，可隨時告知學生。

**Q: 可以同時管理幾個班級？**
A: 目前沒有上限，可根據需要建立多個班級。

**Q: 如何聯絡技術支援？**
A: 點選頁面右下角的「回饋」按鈕。

**Q: 學生的資料安全嗎？**
A: LingoLeap 符合教育數據保護規範，所有資料加密儲存，不會對外分享學生個人資料。
