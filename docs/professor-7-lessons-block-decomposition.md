# 教授七課：實際 block 拆解（不是紙上談兵）

把 7 課 DOCX 逐字讀完，用先前宣稱的 block palette 硬套。**結論先講：thesis 成立（7 課全拆得出來、共用同一套 block），但我原本的 11-block palette 漏了東西，做了才發現。**

## ⚠️ 做了才發現我漏的（Young 的提示是對的）

只看「表格維度」時我漏掉這幾個 block——它們不在表格裡，在段落文字/插入小文本裡：

| 漏掉的 block | 哪裡冒出來 | 為何重要 |
|------------|-----------|---------|
| **B0 embedded_passage（插入小文本）** | G6-L22 孟嘗君、大象有多重；G6-L23/L24/L25 引用課文某段；圖文課的「先讀第N段」 | **這就是你說的「有補充資料、不用看課文」**——聚光燈自備一段小文本，題目掛在它身上，不是本課課文 |
| **B-guide（教學脈絡敘述：小祕訣/步驟/「我們可以這樣思考」）** | 全部課 | **就是教授說「不見的教學脈絡」**。它是結構化的 step 引導，不是裝飾 |
| **B10 拆成兩種 referent** | 圖（G7-L28/29）vs **資料表格**（G7-L30 表一/表二 + 註解 + 跨表比對） | 圖文整合 ≠ 只有圖。G7-L30 是「文＋表」，還要讀註解、跨兩張表交叉推論 |
| **B4 變異比我想的大** | 4x3 簡單填 vs 9x3 巢狀(問題/解決1/解決2/結果) vs 段落定位填 vs 推論填 | 仍是一個遞迴元件，但參數空間大 |

→ palette 從 11 修正為 **~14**。**但核心論點反而被證實**：7 課版面天差地遠（摘要敘事 / 多步驟引導 / 圖文 / 文表），**全部由同一套 ~14 block 不同順序組成**。

## 修正後的 block palette（~14）

```
互動類:  B1 詞語填代號 | B2 單選 | B3 複選 | B4 結構表格填空(flat/nested/定位/推論)
         B5 線索→特質配對 | B6 自由作答(LLM批改) | B7 畫線highlight | B8 判斷✓✗/自我檢核

內容類:  B0 插入小文本(passage) | B-guide 教學脈絡敘述(step/小祕訣) | B10 圖|表 referent(綁段落)
scaffold: 標頭/計時/我的表現/詞語解釋表/影片
```

## 七課逐課拆解

### G6-L22 雞鳴狗盜（摘要-問題.解決.結果，nested 最複雜）
```
B1 詞語(8題) → B-guide「好故事為什麼…」
→ B0 孟嘗君小文本 + B2×4(主角/問題/解決/結果)        # 補充文本①
→ B0 大象有多重小文本 + B2×4(同結構)                  # 補充文本②(進階)
→ B4 重點表 9x3 nested: 問題│解決{問題1,解決1,結果1,問題2,解決2,結果3}│結果, 含【】填空
→ B11 MCQ×5
```

### G6-L23 老鷹紅豆（摘要，多步驟引導最完整）
```
B1 詞語 → B-guide
→ 一、找問題:  B-guide祕訣 → B3(3選1找重點句,課文句) → B-guide「這樣思考」 → B2(2選1精簡)
→ 二、找解決:  B-guide祕訣 → B3(3選2複選) → B2(2選1精簡)×2
→ 小試身手:    B0(課文第5段) + B7畫線 + B2(2選1)
→ 三、找結果:  B-guide → B3(3選1) → B2(2選1)
→ B8 自我檢核×3
→ B4 重點表 5x2: 問題/解決(誰+做什麼)/結果/迴響, 含【】

### G6-L25 第一張股票（摘要，重點表多「段落定位」填空）

### G7-L28 肉湯腐敗（圖文整合，圖=實驗示意圖三情境）
```
B-guide說明(圖文題比重↑) → B0(課文) → B-guide「圖不是裝飾」
→ 步驟❶看圖: B10(圖一,三情境) + B2×5(標題/幾情境/呈現方式/比較什麼/猜主旨)
→ 步驟❷文圖對應: B3(4選2 段1~2在描述什麼) + B2(段3) + B10綁段+B2×3(三情境各對應哪段)

→ 步驟❹: B-guide(看圖說說看,口說)

### G7-L29 四張圖看地球暖化（圖文整合，4 練習平行結構 + 自由作答）
```
B-guide說明 → B0(課文) → B-guide(承上一課)
→ 練習一~四 (每練習綁一段+一圖,平行):
    B7畫線(要看圖的地方) → B-guide小祕訣 → B2(這段看圖什麼) → B10(圖N) + B2×N(圖在說什麼/對應)

→ 練習五統整: B2(把四段四圖串起來)
→ B8 自我檢核×3 → B11 MCQ×5
```

### G7-L30 都是八哥（圖**表**整合 — 最複雜，跨兩表交叉推論）
```
B-guide說明(來回看文/圖/表) → B0(課文) → B-guide
→ 練習一(段1 vs 圖一):   B10(圖一) + B2×2
→ 練習二(段2 vs 表一):   B7畫線 → B2(看表什麼) → B10(表一資料表) + B3複選×2(支持句的證據) + B2×2 + B2(整合句)
→ 練習三(段3 vs 表二):   B10(表二) + B3複選 + B2(讀**註解**的功能) + B2×N + B3(跨回表一找關聯)
→ 練習四(段4 vs 表一+二): B2(回表一推論) + B6自由填空推論(白尾八哥__,臺灣冠八哥__ = 結合表+段落)
→ B8 自我檢核×5
→ B11 MCQ×5 (多題需「同時整合段落+表一+表二」)
```

## 這證明了什麼

1. **7 課 = 同一套 ~14 block 的不同 sequence**。摘要課重 B0+B4，圖文課重 B7+B10+B2，文表課重 B10(表)+B3+B6。沒有任何一課需要「新寫一種程式」。
2. **你點的兩個盲點都命中**：①「補充資料、不用看課文」= B0 插入小文本（我只看表格維度時完全沒看到）②教學脈絡 = B-guide（被現平台丟掉的）。
3. **重點表(B4)** 7 課全有，從 4x3 到 9x3 nested，是同一個遞迴表格元件吃不同參數。
4. **圖文整合的真正難點**不是「圖」，是 **B10 要綁定「第 N 段 ↔ 第 N 圖/表」+ 跨多表交叉**（G7-L30）。這是 block 的屬性（referent + paragraph binding），仍是一次性工程。

## 對 #2079/#2080/#2083/#2084 的意義
- #2079(G7-L29)/#2080(G7-L30) 不是「逐課刻」，是把這份 sequence 填成 layout schema → 渲染。難的是 B10 圖/表 referent + 段落綁定，做一次七課共用。
- 缺的素材：圖文課需要把 DOCX 裡的圖/表抽成獨立 asset（G7-L30 的表一/表二要變成可渲染資料表 + 註解）。
