## 步驟 0 — 先看 DOCX 裡有什麼原始資料

**Young 問**：Docx 本身有沒有什麼 xml 之類的 raw data 要先抽出來？

**用了什麼**：`zipfile` 直接開 DOCX（它就是一個 zip），讀 `word/document.xml` 與
`word/styles.xml`。

**看到什麼**：

```
document.xml   857,932 字元
段落 481   表格 12   圖形 53   文字方塊 112
顏色       {000000: 308, FF0000: 19, 3A3A3A: 16}
符號       {F0FE(☑): 12, F052: 1}
嵌入圖片   24 張 (image1–image24.png)
```

### 🔴 這一步最重要的發現：作者已經把整份文件語意標好了

`styles.xml` 裡有 **24 個「教材：」開頭的具名樣式**：

| 樣式 | 它回答的問題 | 我原本用什麼猜 |
|---|---|---|
| `教材：課文內文` | 這段是不是課文？ | `_MIN_BODY = 46` 長度門檻 |
| `教材：課文標題` / `課文作者` / `課文行數` | 標題？作者？行號？ | 位置 + 長度 |
| `教材：標題名稱` / `標題數字ㄧ` / `Level標題` | 這行是不是章節標題？ | 前綴 `◎`/`※` 比對 |
| `教材：練習題目` / `練習題目（文字）` / `練習題目(1)` | 這是題目嗎？ | 圓圈數字形狀 |
| `教材：(1)＿：填空題目` | 這是填空題嗎？ | `【】` 括號比對 |
| `教材：教師解答` / `教師解答文字框` | 這是答案嗎？ | 「沒有框的那個是答案」 |
| `教材：表格文字` | 表格內容？ | 表格幾欄幾列 |
| `教材：練習提示（雙底線）` | 這是提示還是內容？ | 尾括號形狀 |
| `教材：任務(文字框)` | — | 完全沒處理 |

**我用 regex 猜的每一個問題，文件裡都有明確答案。**

今晚只用到 `教師解答` 一個（#2555），另外 23 個從來沒被讀過。

**決定**：待 Young 確認 —— 這一步的產出改變了後面的做法（如果樣式覆蓋率夠，很多判斷不必
靠看畫面，但仍需畫面驗證樣式有沒有被正確套用）。
