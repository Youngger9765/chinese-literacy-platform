# 學前聲韻處理、快速唸名與視覺記憶能力預測小一學童識字困難效能之檢測

> 宣崇慧、蘇政輝、陳必卿、余孟儒、王涵、張文真、邱郁芬
> 特殊教育研究學刊，37(1)，53-78
> DOI: 10.6172/BSE.201203.3701003

## 摘要

追蹤研究，探討幼兒入學時四類認知技能（聲韻處理含聲韻覺識與聲韻解碼、快速自動唸名 RAN、視覺記憶）對一年級下學期識字困難的直測效果。N=330 名幼兒→269 名國小一年級。篩出識字困難 37 名（Z<-1）及正常 50 名（Z>0.5），共 87 人進行區辨分析

## 核心發現

- 識字困難者的直測變項為**聲韻解碼**、**快速自動唸名（RAN）**、以及**視覺記憶**，總正確性為 **79.3%**
- **學前數字 RAN（25.4%, p<.001）** 可長期直測四年級的閱讀理解表現
- 到了一年級，以**聲韻覺識**最強，分別獨立解釋二年級（24.5%, p<.001）、三年級（10.8%, p=.005）閱讀理解能力
- 聲韻處理在開始習字的一二年間較為重要
- RAN 在不同識字學習發展階段皆有顯著相關

### 雙缺陷假說（Double Deficit Hypothesis）
- 持續型識字困難：注音解碼及 RAN 顯著低
- 將「持續型」與「晚發型」兩組拼起來，可直測多數（80%）的「晚發型」識字困難者
- **RAN + 聲韻解碼 + 視覺記憶**三者組合的區辨效能最佳

## 對 LingoLeap 的啟示

- **RAN 是最強的長期預測指標** — 學前數字唸名速度可預測四年級閱讀理解，我們完全沒有
- 曾教授專訪也建議醫師用 RAN 做篩檢，2 分鐘內完成
- 如果 LingoLeap 未來要做「閱讀困難篩檢」功能，RAN + 聲韻覺識 + 視覺記憶是三大核心指標
- 目前我們只測「朗讀流暢度」（CPM + accuracy），這是更上層的能力，底層的 RAN/聲韻覺識都沒測
