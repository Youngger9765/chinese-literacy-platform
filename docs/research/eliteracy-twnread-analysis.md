# 數位讀寫網（eliteracy.twnread.org.tw）平台分析

> 研究日期：2026-04-02
> 研究目的：分析台灣閱讀文化基金會「數位讀寫網」的功能架構、教學方法論與評量設計，提取可供 LingoLeap 參考的模式

---

## 一、平台概述

數位讀寫網由**財團法人台灣閱讀文化基金會**建置，屬於教育部國教署「數位閱讀與寫作學習實施計畫」的核心平台，目標是提升國中小學生的數位閱讀素養與自主學習能力

### 基本資訊

| 項目 | 內容 |
|------|------|
| 網址 | https://eliteracy.twnread.org.tw |
| 營運單位 | 財團法人台灣閱讀文化基金會 |
| 適用對象 | 國小三年級以上（刻意排除低年級，避免過早接觸數位裝置） |
| 費用 | 免費 |
| 學術背景 | 柯華葳教授（PIRLS 台灣計畫主持人）主導設計 |
| 技術架構 | React SPA + ASP.NET 後端（新舊版本並存） |

### 核心理念

平台以「鷹架式學習」為設計核心，讓學生在結構化的支持系統中自主學習，逐步發展從基礎識讀到高階批判思考的能力，最終達成 12 年國教自主學習的目標

---

## 二、三大學習模組（PP → DP → EP）

數位讀寫網將學習內容組織成三個漸進式模組，形成完整的閱讀素養發展路徑：

### 2.1 基礎讀寫（Primary Process, PP）

**目標**：訓練學生理解句子、段落與短文的基礎能力

包含四個互動式練習工具：

| 工具名稱 | 功能說明 | 培養能力 |
|----------|----------|----------|
| **快打高手** | 依照隨機出現的題目，在格子裡輸入相同的字詞 | 打字速度與準確度，注音符號熟練度 |
| **句句實言** | 將字詞組合成完整通順的句子 | 語法結構理解，句型組織能力 |
| **長話短說** | 閱讀短文，寫出摘要，選出文章中的關鍵字 | 摘要能力，關鍵訊息提取 |
| **讀出滋味** | 閱讀短文，讀出文章背後的滋味 | 推論理解，深層語意掌握 |

**設計特點**：
- 題材取自教科書課文，確保與學校課程銜接
- 從最基礎的輸入能力（打字）開始，逐步進階到理解力
- 遊戲化闖關機制，降低學習門檻

### 2.2 深度讀寫（Deep Process, DP）

**目標**：擴展閱讀廣度，培養多文本閱讀與批判思考能力

- 共 **31 個題組**，由 PIRLS 2021 受託研究團隊（張郁雯教授主持）設計
- 以**學科領域閱讀**為主，輔以社會情緒表達、人際關係、生命教育等議題
- 包含 **ePIRLS 2016 試題**作為練習資源
- 核心任務：閱讀兩篇以上文章後，找出觀點互補或矛盾之處，判斷論據是否合理

**評量設計依據 PIRLS 四層次閱讀理解歷程**：

| 層次 | 名稱 | 說明 | 認知要求 |
|------|------|------|----------|
| 1 | **直接提取** | 找出文本中明確陳述的訊息 | 看懂字詞即可定位答案 |
| 2 | **直接推論** | 連結文章中兩項以上訊息進行推論 | 因果關係、人物關係、代名詞指涉 |
| 3 | **詮釋整合** | 歸納故事主題、人物特點、語氣 | 跨段落整合，主旨歸納 |
| 4 | **比較評估** | 以批判思維評價內容，連結現實世界 | 最高層次，需個人觀點與客觀判斷 |

前兩層為「直接理解歷程」，後兩層為「詮釋理解歷程」

**設計特點**：
- 答案「合理但無絕對標準」，培養批判思考而非背誦
- 多文本比對是核心設計，不只讀一篇
- 題組涵蓋跨領域議題，不限於語文

### 2.3 線上探究（Explore Process, EP）

**目標**：培養數位環境中的專題探究與資訊素養能力

**探究五步驟框架**：

```
定義問題 → 搜尋資訊 → 瀏覽資訊 → 處理/整合資訊 → 呈現/溝通資訊
```

1. **定義問題**：學會設定明確的學習目標與探究方向
2. **搜尋資訊**：有目的地搜尋（purposeful searching），不是漫無目標地瀏覽
3. **瀏覽資訊**：判斷網路資訊的複雜性與多樣性
4. **處理/整合資訊**：選擇、判斷、統整來自不同來源的資訊
5. **呈現/溝通**：將探究成果組織表達

**小組合作機制**：
- 以小組為單位進行專題探究
- 強調同儕互學（peer learning）
- 教師角色從「知識傳遞者」轉為「學習引導者」

**年度競賽——柯華葳線上數位閱讀專題探究競賽**：
- 對象：國小四年級以上至國中
- 初賽：線上提交探究報告（約 3 個月期間）
- 決賽：現場發表（國立公共資訊圖書館）
- 提供校際交流與成果展示機會
- 以柯華葳教授命名，紀念其對台灣閱讀教育的貢獻

## 三、教學方法論分析

### 3.1 鷹架理論的系統性應用

數位讀寫網最突出的特點是將 Vygotsky 鷹架理論（Scaffolding）系統性地落實在平台設計中：

- **漸進式移除支持**：PP 提供最多鷹架（打字提示、詞彙提供），DP 減少提示要求自主推論，EP 幾乎完全自主探究
- **近側發展區設計**：每個模組都略高於學生現有能力，但在鷹架支持下可達成
- **從被動到主動**：PP 是回應式（回答問題），EP 是主動式（自己定義問題）

### 3.2 PIRLS 國際閱讀評量框架的在地化

- 直接採用 PIRLS 四層次理解歷程作為評量骨架
- 將 ePIRLS（數位閱讀評量）的情境模擬融入平台
- 題組設計由 PIRLS 研究團隊操刀，確保學術品質
- 台灣在 PIRLS 2021 的表現：紙本閱讀成績優異但數位閱讀相對弱，平台正是回應此落差

### 3.3 從單文本到多文本的進階設計

這是數位讀寫網最值得學習的教學法設計：

```
單句理解（PP-句句實言）
  → 短文理解（PP-讀出滋味）
    → 單篇文章深度理解（DP 基礎題組）
      → 多篇文章比較分析（DP 進階題組）
        → 網路多來源探究（EP）
```

### 3.4 「有目的的搜尋」教學法

EP 模組強調的核心概念——學生在進行數位閱讀前必須先明確定義問題，有了問題才去搜尋，搜尋到資訊後要判斷可信度，最後整合多來源資訊形成自己的觀點

這與傳統「先讀再想」的順序不同，是「先想再找再判斷」

## 四、UI/UX 設計模式觀察

### 4.1 架構設計

- **三模組漸進結構**：PP → DP → EP 的路徑清晰，學生知道自己在哪個階段
- **闖關式進度機制**：基礎讀寫採遊戲化闖關設計，完成一關才能進入下一關
- **分離式工具設計**：每個練習工具獨立運作，學生可自由選擇練習項目

### 4.2 帳號與角色系統

- 支援**教師帳號**與**學生帳號**兩種角色
- 教師可追蹤學生學習進度
- 與學校系統整合（透過教育雲端帳號）

### 4.3 值得注意的設計選擇

**優點**：
- 刻意排除低年級使用，展現教育理念優先於使用者數量的態度
- 題材與教科書課文銜接，降低教師導入門檻
- 免費開放，消除使用障礙

**可改進之處**：
- 網站為 React SPA 但 SEO 不佳（curl 無法取得內容）
- 新舊版本並存（.aspx 舊頁面與新 React 前端），使用者可能感到混亂
- 缺乏即時 AI 互動（目前是靜態題庫 + 人工評審模式）

## 五、對 LingoLeap 的啟示與可採納模式

### 5.1 可直接採納的設計模式

#### （1）PIRLS 四層次提問框架

LingoLeap 的 ComprehensionChat（蘇格拉底式對話）可以參考 PIRLS 四層次來設計 AI 提問策略：

| PIRLS 層次 | LingoLeap 對應做法 |
|-----------|-------------------|
| 直接提取 | AI 先問「文章提到了什麼？」確認學生讀懂基本內容 |
| 直接推論 | AI 追問「為什麼會這樣？」引導因果推論 |
| 詮釋整合 | AI 要求「這篇文章的主旨是什麼？」歸納整體意義 |
| 比較評估 | AI 挑戰「你同意作者的看法嗎？為什麼？」培養批判思維 |

目前 LingoLeap 的蘇格拉底 agent 有 3 階段 5 題的設計，可以明確對應到這四個層次，讓教學目標更清晰

#### （2）漸進式學習路徑設計

數位讀寫網的 PP → DP → EP 三階段模式值得參考：

- **基礎階段**（對應 LingoLeap 的生字練習、聽寫練習）：建立字詞基本功
- **理解階段**（對應 LingoLeap 的課文理解、逐段朗讀）：單篇文本深度理解
- **應用階段**（目前 LingoLeap 較弱）：跨文本比較、知識遷移

LingoLeap 的「知識站」（KnowledgeStation）步驟有潛力發展成類似 DP 的多文本閱讀模組

#### （3）「先想再找」的探究式學習

EP 的「定義問題 → 搜尋 → 判斷 → 整合 → 表達」框架，可作為 LingoLeap 未來發展「自主探究」模組的參考骨架

### 5.2 差異化優勢——LingoLeap 可以做到而數位讀寫網做不到的

| 面向 | 數位讀寫網 | LingoLeap 優勢 |
|------|-----------|---------------|
| 互動方式 | 靜態題庫，學生作答後看解答 | AI 即時對話，動態追問與引導 |
| 個人化 | 統一題庫，所有學生看同樣內容 | AI 根據學生回答調整難度與追問方向 |
| 朗讀指導 | 無朗讀功能 | TTS + 即時朗讀評估（LiveTutor） |
| 卡關偵測 | 無 | stuck_detection_service 偵測學生卡關並主動介入 |
| 學習預測 | 無 | prediction_service 預測學習困難 |
| 遊戲化深度 | 基礎闖關 | XP / 成就 / 連續登入 / 排行榜 |

### 5.3 建議新增或強化的功能方向

#### （A）多文本閱讀比較模組（參考 DP）

目前 LingoLeap 以單篇課文為單位，可考慮新增：
- 同主題兩篇文章比較閱讀
- AI 引導學生找出兩篇文章的觀點異同
- 跨課文學習分析（cross_text_analysis_service 已有基礎）

#### （B）摘要練習工具（參考「長話短說」）

數位讀寫網的「長話短說」是很好的閱讀理解訓練：
- 讀完一段文字後，要求學生用自己的話摘要
- AI 評估摘要品質（是否抓到關鍵訊息、是否遺漏重點）
- 這比選擇題更能測出真正的理解程度

#### （C）句子重組練習（參考「句句實言」）

將打散的詞彙組合成正確句子，是很好的語法練習：
- 可整合進 VocabApplication 步驟
- 比造句更有鷹架（提供了所有詞彙，只需排列）
- 適合作為造句前的暖身練習

#### （D）關鍵字提取能力訓練

數位讀寫網在「長話短說」中要求學生選出關鍵字，這個能力在 LingoLeap 中可以這樣實現：
- 讀完課文後，AI 請學生選出 3-5 個關鍵詞
- AI 根據學生選的關鍵詞判斷理解程度
- 比直接問「這篇文章的主旨是什麼」更低門檻

### 5.4 評量設計的啟示

數位讀寫網的評量設計有幾個值得學習的原則：

1. **答案可以不唯一**——DP 的題目設計允許合理但不同的答案，這與 LingoLeap 的蘇格拉底對話理念一致，AI 不應該只接受標準答案

2. **從封閉到開放**——先用選擇題確認基礎理解，再用開放式問題測試深度思考，LingoLeap 的對話流程可以參考這個遞進

3. **跨領域議題融入**——31 個題組不只有語文，還涵蓋社會情緒、人際關係、生命教育，LingoLeap 的課文選材也可以考慮這個面向

## 六、總結

數位讀寫網是台灣目前最具學術基礎的數位閱讀素養平台，其價值在於：

- 以 PIRLS 國際評量框架為骨架，確保教學方法論的嚴謹性
- PP → DP → EP 三階段設計體現了鷹架理論的系統性落實
- 多文本比較閱讀是國內少見的教學設計
- 探究式學習的五步驟框架（定義問題 → 搜尋 → 瀏覽 → 整合 → 表達）值得所有閱讀教學平台參考

但它缺乏 AI 互動能力、個人化適性學習、即時回饋機制——這些正是 LingoLeap 的核心差異化優勢

**LingoLeap 最值得從數位讀寫網學習的三件事**：
1. 採用 PIRLS 四層次作為 AI 提問策略的分層框架
2. 新增多文本比較閱讀功能（從單篇走向跨篇）
3. 加入摘要練習與關鍵字提取作為閱讀理解的輔助評量
