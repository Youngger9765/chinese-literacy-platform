# 雙閱讀素養：學與教 — 國小中高年級雙閱讀素養教學指引

> 柯華葳教授閱讀研究中心
> 國立清華大學
> 中心主任：陳明蕾
> 來源：https://www.hwaweiko.tw/

## 核心理念

柯華葳教授提出的閱讀教育藍圖：
- **紙本閱讀**是打好數位閱讀的基本功
- 透過**多文本閱讀**串接紙本閱讀與數位閱讀
- 讓學生具備「判斷、選擇與整合多元訊息」的新素養

## 雙閱讀素養學習指標

### A. 搜尋與瀏覽
| 指標 | 數位閱讀能力 | 紙本閱讀對應 |
|------|-----------|-----------|
| A1 | 擬定檢索內容（設定關鍵字） | 使用關鍵字在圖書館資料庫搜尋 |
| A2 | 運用搜尋介面的進階檢索功能定位目標圖文訊息 | — |
| A3 | 找出與閱讀目的有關且明顯的網頁（relevant 1） | 從圖書館目錄找出相關訊息 |
| A4 | 能追蹤網頁瀏覽過程 | 能記錄搜尋與瀏覽歷程 |

### B. 評估
| 指標 | 數位閱讀能力 | 紙本閱讀對應 |
|------|-----------|-----------|
| B1 | 評估訊息的有用性（useful） | 評估文本訊息的有用性 |
| B2 | 從網頁中找出與閱讀目的有關且明顯的訊息（relevant 2） | 從文本找出相關訊息 |
| B3 | 評估網站的觀點或立場（包括看法、偏見） | 知道作者的立場 |
| B4 | 判斷網站訊息的可信度 | 評估文本訊息的可信度 |
| B5 | 從已篩選的網路資訊中，選擇最適當、可行和有用的網站 | 從已累積的訊息，選出最適當的文本 |
| B6 | 摘要出網頁的重點 | 閱讀文本的摘要 |

### C. 整合
| 指標 | 數位閱讀能力 | 紙本閱讀對應 |
|------|-----------|-----------|
| C1 | 描述文章和圖像間的關係 | 圖文整合的閱讀策略 |
| C2 | 針對閱讀目標進行跨網站間的圖文訊息比較及統整 | 多文本閱讀的比較與對照 |
| C3 | 歸納來自不同網頁或網站的訊息 | 多文本閱讀的歸納 |
| C4 | 從多個網頁得出結論，並能使用網站資訊支持所提出的論點 | 多文本閱讀的統整 |

### D. 組織和呈現
| 指標 | 數位閱讀能力 |
|------|-----------|
| D1 | 清楚表達出符合任務、目的及讀者的文章或訊息 |
| D2 | 使用科技撰寫並發表文章、與他人互動、連結其他訊息 |
| D3 | 清楚適當引用或改寫他人的資料及結論 |

## 六年級教學示例：曹操（多文本閱讀）

五節課結構：
1. **評估**：略讀+詳讀課文，找出與曹操相關的訊息並標記
2. **評估**：閱讀第二篇文本（三國演義故事），比較不同描述
3. **評估+整合**：閱讀第三篇（衝突性觀點），分類歸納訊息，認知衝突
4. **評估+整合**：上網搜尋第四篇數位文本，判斷可信度，理解作者立場
5. **組織+形成觀點**：寫作 — 設想自己是歷史學家，論述對曹操的看法

### 數位閱讀融入策略
- **設定關鍵字**：教學生如何設定搜尋關鍵字
- **從標題和簡短說明判斷**：快速判斷搜尋結果是否相關
- **判斷可信度**：官方網站 vs 部落格
- **忽略無關訊息**：廣告、旁邊的延伸資訊

## 閱讀理解的基模運作

- **基模（schema）**：皮亞傑的認知結構理論
- **同化（assimilation）**：新訊息符合既有基模，納入
- **調適（accommodation）**：新訊息不符合，調整基模
- 閱讀心理學：文本內容是一種基模，文章結構也是基模
- 建構出：一般常識 → 程序知識 → 特定學科知識

### 可參考
- 多文本閱讀的教學模式 — 目前 LingoLeap 只有單文本，未來可考慮跨課文比較
- 數位閱讀素養指標（A1-D3）— 可作為 LingoLeap 未來功能規劃的框架
- 「認知衝突」教學法 — 讓學生讀到矛盾訊息，引發思考，很適合 AI 對話設計
