## 策略遞進序列（資料中明確存在）

以下遞進關係**直接從 YAML 資料觀察到**，同一策略在不同課文中由淺到深：

### 1. 推論人物特質（4 級）
```
L08 認識策略 → L09 給理由+勾選 → L10 給理由+寫出 → L11 自行寫理由+特質
```
鷹架逐步移除：從「選」到「寫」

### 2. 推論主旨（3 級）
```
L15 從標題+首末段找 → L16 摘取大意+關鍵語句 → L17 段落推論
```
範圍逐步縮小：全文→段落

### 3. 說明文結構（4 級）
```
L13 認識主題描述 → L18 找舉例與細節 → L19 找小主題 → L20 找小主題+細節
```
複雜度遞增

### 4. 自我提問（3 級）
```
L21 問好奇的問題 → L22 問重要的問題 → L23 四步驟整理想法
```
從開放到結構化

### 5. 解決問題（6 級）
```
L24 觀察證據回答 → L35 推理三要素 → L36 問題解決流程 → L37 科學方法 → L49 說服他人 → L51 生活應用
```
最長的策略線，從被動回答到主動應用

### 6. 用表格整理訊息（3 級）
```
L29 兩組比較 → L30 推論上位概念 → L31 推論趨勢
```
從描述到推論

### 7. 品格力（4 篇，非嚴格遞進）
```
L06 換位思考 | L25 跨文化接納 | L27-28 正向思考 | L34 環保3R
```
主題不同，非能力遞進

### 8. 文言文（4 級）
```
L42-43 一字多義 → L45 閱讀示範(4步驟) → L46 判讀主語 → L47 斷句+判讀主語II
```
從詞到句到篇

### 9. 數位素養 / 媒體識讀（4 篇）
```
L39 辨別網路訊息 → L40 誘餌式標題 → L41 思辨超能力 → L48 假新聞思辨
```

### 10. 圖表素養（3 級）
```
L38 折線圖 → L52 長條圖+圓形圖 → L53 判讀統計圖步驟
```
