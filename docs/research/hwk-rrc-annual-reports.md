# 柯華葳教授閱讀研究中心 年度報告（2022 + 2023）

> 國立清華大學 柯華葳教授閱讀研究中心（HWK RRC）
> 來源：https://www.hwaweiko.tw/

## 2022 Annual Report

- 中心元年（2022 年成立）
- 結構：緣起 → 關注議題 → 跨界結盟 → 研究 → 研創 → 研議 → 影響力
- 柯華葳教授 2020 年 11 月辭世，2020.06 寫下最後的結論文字
- 中心使命：延續柯教授的閱讀教育藍圖

## 2023 Annual Report

- 結構：關注議題 → 研究 → 研創 → 研議 → 影響力 → 老師悄悄話
- 2023 年與**曾世杰教授**及**陳淑麗教授**合作，取得差異化補救教學的珍貴研發資源
- 持續耕耘厚學計畫及雙閱讀素養計畫
- 第一次設置基地典範學校，到校蹲點並輔導學校成為能執行雙閱讀素養教學的學校
- 第一屆雙閱讀素養教案設計甄選
- 第一次辦理國際學術研討會（主題：執行功能與閱讀發展）

## 對 LingoLeap 的啟示

這兩份是機構年報，主要價值在**合作網絡**和**政策脈絡**：
- 中心跟曾世杰/陳淑麗合作 → 我們使用他們的研究成果有正當性
- 雙閱讀素養計畫是教育部推動的 → 如果要申請政府計畫，這是重要背景
- 基地典範學校模式 → 未來 LingoLeap 進學校的參考路徑
