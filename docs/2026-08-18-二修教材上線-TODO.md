抽取跑完會很想直接宣布完成。三個人的框架各戳破一個盲點，**這三條原本不在任何 TODO 上**。

### Sal Khan —— 「內容正確」跟「學生學會」是兩件事

他 2026 年 4 月公開承認 Khanmigo「for a lot of students it was a non-event」，

對照我們：九道門管的是「抽對了沒」（逐字門）跟「畫得出來沒」（渲染門）。
**沒有任何一道門管「學生走得完一課、而且系統知道他學會了沒」。**
→ Phase F。

### 簡立峰 —— 從作家轉編輯，要有 80 分以上的人工把關

抽取是「作家」的活。他強調真正決定品質的是**編輯那一關**。
我們現在有 9 道機器門、**0 個人類簽核迴路**。
這是教師寫的教材，只有淑麗／曾老師能說「這樣呈現是對的」。
→ Phase C1。

### Ethan Mollick —— 鋸齒邊界，所以要抽樣人工覆核

AI 能力是鋸齒狀的：難的做得好、簡單的可能爆掉，而且**邊界形狀不可預測**。
我們誠實記下來的缺口（26 課 `text_carrier: image`、7 課 `answers_printed: false`）
是**看得見的那一側**；看不見的那一側是「門全綠但其實抄錯」的課。
機器門抓不到，因為門比對的就是同一份原稿。
→ Phase C1 的抽樣要**隨機**，不能只挑有缺口標記的那些。

#### A2 結案（2026-08-18）：**門錯，資料沒錯。19 課一個字都沒改。**

那 19 條其實是兩種不同的東西，混在一起看才像「19 個內容缺陷」：

| | 是什麼 | 判定 | 證據 |
|---|---|---|---|
| **17 條「缺 layout」** | 那批課是**訂 skill §⑥.55b 之前**抽的，沒寫 `layout` | **不是缺陷**。`keypoints.yml` 的 `layout` 只有這支門在讀 —— 橋、schema、route 沒有任何一個讀它 | `grep -rn layout backend/app/services/keypoints_to_structure.py` → 0 命中；`backend/app/schemas/` 的 `layout` 全是別的東西（`layout_mode`、route 自己生的 `worksheet_table`） |
| **L0002／L0004 的「整張表會是空的」** | 門說 row 的 key 對不上 `columns` | **假警報**。兩課餵進 runtime 真的走的那條橋都畫得出內容 | L0002 → 4 列（`['五種生存妙招', '【保護色】、【偽裝】…']`）；L0004 → 7 列 |

**根因兩個，都在我們這側：**

1. **叫法漏 flag。** 正規叫法帶 `--legacy-ok`（記在 `docs/evidence/2026-08-17-multimodal-extraction/HANDOFF.md`），
   派工時漏帶 → 那 17 條慣例問題被印成紅的。**這一條是我（工頭）造成的，不是這批抽取造成的。**
2. **門把自己修掉的症狀寫進判準。** `git log` 顯示這支門和橋的退路是**同一個 commit `32fce2b4`**
   進來的：那個 commit 一邊在 `keypoints_to_structure._columns_to_structure_table` 加了
   「欄名對不上就改用 row 自己的 key」的退路（註解**直接點名 L0004**），一邊把退路存在之前的
   症狀寫成門的判準。

**做了什麼（`scripts/keypoints_shape_gate.py`）：**

- 第 2 項不再猜形狀，**直接呼叫橋**看它吐不吐得出內容 —— 這條不會跟橋漂移，因為它就是橋
- 逐列檢查補上同源退路（欄名對不上就看 row 自己的 key）
- **預設改成放行舊課的慣例問題，`--strict` 看全部欠帳**。理由：一道**預設恆紅的門會被訓練成無視**，
  這 19 條就是這樣被當成待解問題掛了一整天。`--legacy-ok` 保留為 no-op，既有 SOP 叫法不會壞
- ⚠️ 但放寬只到「慣例」為止：**「表是空的」任何課都擋，包含 LEGACY 名單上的** ——
  不然那份名單會變成 19 課的永久免死金牌
- 回測鎖 `backend/tests/test_keypoints_shape_gate_empty_claim_2736.py`（13 條），
  含正向對照（L0017 跟 L0004 `columns` 一字不差，差別只在 key 對不對得上，兩課都畫得出內容
  ⇒ 那個維度不能預測「表會不會空」）、負向對照（真的畫不出東西的形狀，門仍然抓得到）
  與 7 個 mutation
