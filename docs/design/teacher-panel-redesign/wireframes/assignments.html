設計依據：README §3 —— 讀 code 發現 建立正式作業時系統已經自動把課文同步進自學課文庫（#997），所以「自學課文庫」欄不是全新功能，是把老師原本看不到的既有同步行為攤開顯示。「已在自學圖書館上架」這行字直接回應現場回饋「指派完只出現在這一頁」——根因不是資料真的消失，是教師端從來沒有顯示「這份課文現在在自學圖書館裡」這件事，讓老師誤以為石沉大海。

＋ 建立作業（精簡示意，非完整表單）

課文挑選器優先顯示「已在自學課文庫」的課文（體感更快），但仍可搜尋全部 175 篇平台課文或自建教材。設定到期日、目標 CPM／正確率後建立 —— 若此時選的課文還不在課文庫，建立時會自動同步加入（沿用既有 #997 行為，不是新機制）。
