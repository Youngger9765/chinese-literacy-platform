# PRD：老師端畫面對齊均一（逐頁一模一樣，能更好的地方更好）

Young 2026-10-13：「老師介面好好檢查，UIUX 去跟均一比較，務必做到一模一樣，甚至更好」。

對照基準（均一實際畫面＋我們改版前畫面）放在私人 repo `kist-curriculum/benchmarks/junyi-teacher-ui/`，
本 repo 是公開的，所以截圖不放這裡。延續 `PRD-junyi-style-class-flow.md`（流程已對齊），本份只管**畫面版面**。

## 1. 問題與成功指標

流程已仿均一，但畫面沒有：桌機 1280 寬時主內容擠在右側 744px 的卡片、左邊空一大塊；
學生名單被「加學生」表單推到摺線下；指派任務空空一行字。

成功指標：1280 與 390 寬，逐頁截圖跟均一同頁並排，下列每條驗收都成立（以截圖判定，不以程式碼判定）。

## 2. 逐頁差距與要求

### P1 版面骨架（所有班級頁）
| 均一 | 我們現在 | 要改成 |
|---|---|---|
| 三個分頁（班級設定／指派任務／班級數據）是**滿版**大分頁列，選中的那頁整格深色底 | 分頁擠在卡片內、小字 | 滿版分頁列，選中整格高亮，字級 ≥ 20px |
| 左欄：老師頭像＋名稱＋帳號、「建立班級」、「我的班級」清單（目前班級高亮，點了直接切班）、「所有學生」 | 左邊空白一大塊（約 280px），要按「返回班級列表」才能切班 | 班級頁左欄常駐「我的班級」清單，可直接切班；頂部放「建立班級」 |
| 內容區吃滿剩下寬度 | 內容卡片固定約 744px 寬、置右 | 內容區吃滿（扣掉左欄），最大寬 1200px |

### P2 班級設定
| 均一 | 我們現在 | 要改成 |
|---|---|---|
| 標題列：班名＋鉛筆（就地改名）、「班級代碼: XXXX ⓘ」 | 班名＋「編輯」按鈕；加入代碼另一張大卡片 | 班名旁鉛筆就地改名；班級代碼與複製／QR 縮到標題列同一行 |
| 統計格：班級人數 N 位、組別數 N 組 | 只有一行小字「2 位學生」 | 統計格（人數；分組做好後加組別數） |
| 右上圖示按鈕列：新增學生、新增座號、分組、解散班級 | 文字按鈕：編輯／停用／匯出 CSV／解散班級 | 圖示＋文字按鈕列：新增學生、匯出 CSV、列印帳密卡、停用、解散班級 |
| **學生表直接在最上面**：顯示名稱（可改）、帳號、建立者、重設密碼按鈕、操作 | 學生名單被「加學生」大表單推到摺線下 | 學生表置頂；「加學生」收進「新增學生」按鈕開的彈窗 |
| 表格下方「指派任務」主按鈕 | 無 | 表格下方「指派任務」主按鈕，跳到指派任務分頁 |

### P3 指派任務
| 均一 | 我們現在 | 要改成 |
|---|---|---|
| 「選擇班級」下拉＋班級代碼＋複製代碼 | 無 | 班級下拉（切班）＋代碼 |
| 「建立任務 ＋」藍色主按鈕、「管理任務」 | 右上「建立作業」＋下方摺疊「建立與管理作業」 | 「建立作業 ＋」主按鈕＋「管理作業」，移除摺疊區 |
| 狀態圖例：有預定時間／未完成（黃）／已完成（綠）／遲交（紅） | 無 | 同樣圖例（我們多一個「進行中」，保留） |
| 沒任務時：藍色提示條＋**學生 × 任務矩陣**（就算沒任務也列出學生） | 一行「這個班級還沒有指派作業」 | 永遠顯示矩陣：列＝學生、欄＝作業；沒作業時顯示提示條＋學生列 |

### P4 班級數據
| 均一 | 我們現在 | 要改成 |
|---|---|---|
| 班級下拉、學生數、能量點數 | 無班級切換 | 頂部班級下拉＋學生數 |
| 左側報表選單＋日期區間（最多 90 天） | 左側選單已有；無日期區間 | 加日期區間選擇（預設最近 7 天） |

### P5 建立班級
| 均一 | 我們現在 | 要改成 |
|---|---|---|
| 置中彈窗 | 頁內卡片 | 置中彈窗 |
| 名稱＋「加入學生的方式」二選一：幫學生建帳號（數量）／學生已有帳號 | 名稱＋年級；建完才加學生 | 彈窗內就能選「幫學生建帳號（貼名單或填人數）」／「學生已有帳號（給代碼）」／「匯入均一班級」，一步建好 |

### 比均一更好（保留／加強）
- 匯入均一班級學生（均一沒有反向匯入）
- 帳密卡印姓名
- 「進行中」狀態
- 手機 390 寬：均一沒有手機版，我們每頁都要能用（不橫向捲動、分頁與左欄改成上方下拉切班）

## 3. 需要決定的
- **分組**：均一有分組（組別數、指派給組別）。我們資料庫沒有組別，要加資料表（需要 migration）。未決前先不做，統計格先只放人數。

既有前端測試（lint、vitest）全綠；正式站真實操作走一遍：建班→加學生→指派→看數據。
