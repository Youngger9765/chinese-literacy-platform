## 一、三大重點功能 Demo（現場走真學生流程給教授看）

### 1. 逐段／全文朗讀
- **現場動線**：小明登入 → 進課 → 逐段朗讀 → 學生錄音 → AI 即時判斷（左課文／右判斷雙欄）→ 朗讀對照（綠=正確／藍=通融同音／紅=唸錯）→ 全部段落完成 → 「再讀一次」重錄
- **請教授看的重點**：評分準確（改 deterministic，不再誤判）、靜音／噪音不再假通過、逐字實唸對照清楚

### 2. 閱讀聚光燈（閱讀策略主軸）
- **現場動線**：進課 → 閱讀聚光燈 → 引導故事（例：烏鴉喝水）＋課文故事 → 題號 ❶❷❸❹ → 學生輸入答案即時批改「✓ 答對了」→「參考課文」對照
- **請教授看的重點**：教學脈絡完整還原、斷詞題號正確、8 策展課（G6-L22~25 摘要策略／G7-L28~30 圖文整合）

### 3. 文章重點表（知識補給站）
- **現場動線**：進課 → 重點表 → 三欄三層（問題／解決／結果 × 各段）→「怎麼玩」示範 → 學生填答 → AI 檢查 + 提交
- **請教授看的重點**：階層視覺、直接呈現、填答即評分

## 二、回應教授 6/5 改進意見（請教授逐條驗收「已改成什麼」）
