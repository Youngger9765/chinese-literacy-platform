## 一、Demo 順序（刻意：先穩後險）

> 先 demo 已驗、純畫面呈現的強項建立信任；朗讀（含即時語音辨識，教授上次現場痛點）**放最後 + 備 plan B**

### 1. 閱讀聚光燈（已驗 7/7，最穩，先打）
- 動線：進課 → 閱讀聚光燈 → 引導故事（烏鴉喝水）+ 課文故事 → 題號 ❶❷❸❹ → **文字輸入題**輸入答案即時批改「✓ 答對了」→「參考課文」對照
- 課：G6-L22

### 2. 文章重點表
- 動線：進課 → 重點表 → 三欄三層（問題／解決／結果 × 各段）→「怎麼玩」示範 → 填答 → AI 檢查
- 課：G6-L22
- 📎 **閱讀聚光燈與文章重點表操作說明**：[2026-07-20-閱讀聚光燈與文章重點表_操作說明.pdf](./2026-07-20-閱讀聚光燈與文章重點表_操作說明.pdf)

### 3. 逐段／全文朗讀（放最後，帶 plan B）
- ⚠️ **高風險環節**：即時語音辨識，正是教授上次痛點（辨識失敗／唸 5 次過不了）；會議室噪音也可能被靜音 gate 拒收
- **plan B（先做）**：先播**事先錄好的「成功朗讀 → AI 判斷 → 評分」螢幕錄影**，再視收音情況現場試
- 錄影裡展示的賣點：評分改 deterministic（不再 58% 誤判）、靜音／噪音不假通過、逐字實唸對照（綠正確／藍通融／紅唸錯）
- 📎 **靖杭朗讀功能簡報**（7 頁，可當 plan-C 靜態備援）：[2026-07-20-朗讀功能簡報.pdf](./2026-07-20-朗讀功能簡報.pdf)——逐段／全文操作介面 + 使用流程 + 成績趨勢 + **正確性驗證**（故意漏念第 2／6 段 AI 全標灰、同段漏句也抓、四色圖例），內含 staging 實測截圖（課文《白鯨救援》）

## 三、平台級請教授對齊
1. **全站聚光燈**：目前 **7 策展課**上線（G6-L22~25 摘要策略／G7-L28~30 圖文整合）；adapter 自動產出機制已建、**尚未上線**，audit 後補技術修 + 抽驗品質再決定全站 flip（呼應教授「先盤點分類再排程」）
2. **與老師的核對流程**：教授核心要求＝可複製 pipeline + 與老師高效核對，不是逐課手修 → 立案方向
3. **180 課全上線時程**（教材預計 8 月完成）
