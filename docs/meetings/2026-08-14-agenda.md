### ⭐ 上次標的最高風險，查證後不成立

8/7 議程寫：「QR code 印上紙不可撤回，而 #2561① 正要重排 lesson_code → URL 必須綁不變碼」。

實際查 `backend/scripts/build_demo_reading.py:142`：

```python
url = f"{base_url}/demo-reading/{plan.lesson_id}/{plan.kind}"
```

`lesson_id` 型別是 `int`（= story_id），**不是** 會被重排的 `grade_code`。而 #2675 明確不動任何 story_id。
→ **重排課號不會讓已印出的 QR 失效**，這條解除。

### 但要立一條紅線

重排可以改 `grade_code` / `display_order`，**永遠不可以重用或重新指派既有 `story_id`**。
特別是「新增 12 課」要配新 story_id、「總表有但線上無 13 課」不可以拿舊 id 頂替 ——
一旦動到，所有已印出的 QR 全部指到錯的課，而且紙收不回來。

### 要決定的

1. **178 筆課號異動誰簽、什麼時候簽**（Young + 淑麗）—— ② 內容更新完全卡在這
