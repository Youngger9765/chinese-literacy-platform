# 教授團隊平台 Demo 回饋會議紀錄 2026-06-05

> 課程顧問老師團隊對學習平台進行逐步 demo，逐項點出學習流程的 UX / 內容 / 功能問題。
> 本紀錄聚焦可執行的回饋與對應處理，依元件分類。原始逐字稿與教材設計細節為顧問團隊
> 智慧財產，未納入本公開紀錄。

## 1. 學習流程 UX（套用所有課）— #2082 ✅ 已處理

- **朗讀**：簡介朗讀不應念出「文體 · 策略」標題段，直接念課文內文；速度略快（約 260–270 字/分，聽讀用）；按鈕用詞簡化為「朗讀」。
- **本課學習策略**：移除屬於「讀課文」階段的標記說明項；策略名以明顯色塊 highlight，不藏在標題下；結構策略加引號保留「結構」二字。
- **開始學習**按鈕加大、置明顯處（直式螢幕原本看不到）。
- **學習步驟列表**：移除假可點清單；以持久的步驟導航 + 進度（第 N / M 步）取代。
- **標記功能**：補首次使用說明（依裝置顯示滑鼠拖曳 / 觸控滑過）。
- **語詞理解配對**：放大左側「語詞解釋」字級；欄位改名（語詞解釋 / 本課語詞）；答對明確稱讚、答錯提示「再試試看」；依裝置誠實標示「拖曳 / 點選」。
- **填空題**：點選即判（移除多餘「確認答案」）；答錯不直接顯示正解；文字置左、加題號、縮小填空框；選項代號（ABCD）以開關控制可 A/B。
- **年級標示**：學生端改「第 N 級」中性標示（避免高年級學生看到低年級字樣的不適）。

## 2. 閱讀聚光燈 — #2083（由實習團隊處理中，PR 進行）

- 入口 icon 太小；申論/填空無即時回饋、教師端看不到作答。
- **核心**：紙本以引導故事先建立策略概念再進本課，數位版此教學脈絡缺失；左右版面未對應。需重新設計（教學脈絡 + AI 即時批改）。

## 3. 文章重點表 — #2084（後續）

- 入口可見性不足；視覺層次未呈現「問題—解決—結果」階層與次層結構。可做可複製模板。

## 4. 圖文整合（7/1 核心單元）— #2085 ✅ 閱讀對照已處理

- 原本圖縮在角落、點放大會遮住文字、圖文無法並陳，且圖序看不出來。
- **已處理**：改為**逐段左右對照** —— 每段課文與它引用的「圖N」並排（非圖庫橫滑）；圖內縮放不遮文字；圖號改由資料驅動配對（修正了圖檔順序與圖號不一致的問題）。
- **後續**：教材設計希望「寫練習時每題自動帶出該題的段落與圖」（逐題對照），列為後續。

## 5. 內容 / 資料 — #2086 ✅ 已處理

- 閱讀理解題數異常（應 5 題卻顯示 3）→ 修復課文資料。
- 字搜直橫分布失衡 → 加入方向平衡；操作說明文案優化、移除多餘計數提示。

## 6. 檔案格式 / 上傳 / 開源

- Word→PDF 轉檔跑版與字體錯亂；規劃同時提供 Word + PDF 並處理字型相容。
- 上傳學習單（拍照存檔）與 OMO 批改結果串接學習進度 → #2087 ✅（已串接 LearningSession）。
- 成果規劃開源（程式碼 + 教材公開於 GitHub），歡迎社群貢獻。

## 7. 其他

- classrooms 課文清單 API 在特定資料下回 500（非數字課次代號）→ #2098 ✅ 修復。
