## 四、MVP 實測（15 min）

每個人打開 production 網站，自己跑一遍完整的學習流程：

https://lingoleap-frontend-958347263320.asia-east1.run.app

**測試步驟**：
1. 選一篇課文
2. 簡介 → 逐段朗讀 → 生字練習 → 課文理解 → 全文朗讀 → 報告
3. 走完整個流程

**記錄問題**：每人至少提出 3 個問題，開成 GitHub Issue
- 看到什麼覺得怪的？
- 哪裡卡住了？
- 哪裡看不懂？
- 文字太小？按鈕不好按？

**Issue 格式**：
- 標題：`[Bug/UI] 簡短描述`
- 內容：截圖 + 重現步驟 + 你覺得應該怎樣比較好
