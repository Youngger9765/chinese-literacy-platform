## 0.5 架構判斷（2026-08-22，kc gpt-5.6-terra）—— 決定修復順序

問了四題，回來的判斷改變了我原本的優先序。逐題記結論與**代價**，
因為每一條都不是免費的。

### 🔴 最該先修的不是 ②，是「成功判定沒有跟來源覆蓋綁定」

> 目前最危險的不是 ② 分頁不穩，而是 **⑥ 可以交出缺頁、缺題、失真的資料，⑦ 仍給它綠燈**。
> ② 已被 ⑤ 轉成**大聲失敗**（會阻塞產出，但不會悄悄把錯資料送到學生畫面）。
> ⑥＋⑦ 相反：它能讓壞資料以「成功」身分穿過整條管線。
> 這是 **integrity failure 不是 availability failure**，而且學生端會把它放大成教學內容錯誤。

⇒ **先做的不是追 LibreOffice 根因，也不是量 N 架飛機的一致率**，而是把
「來源見證 → yml 欄位 → 忠實度證明」這條鏈建起來。在它存在之前，
任何「門全綠」都只代表**結構像 yml**，不代表學生看到的是原稿的內容。

### Q1 頁碼 vs 內容錨點 —— ⑤ 不夠，頁碼這個抽象本身就錯

⑤ 只防「同一張派工單拿到不同頁數的 PDF」這一種 split-brain。它擋不住：

- **同頁數但版面重排** → ⑤ 放行，而派給飛機的內容範圍已經變了
- **頁數不同但每個錨點都找得到** → ⑤ 阻擋一個其實可以安全執行的任務

> **大題標題與其內容邊界是 SOT，頁碼只是針對某份特定 PDF 即時算出的執行座標。**

```
canonical address:
  start_anchor = 大題標題的正規化文字 + occurrence/context
  end_anchor   = 下一個大題標題，或文件結尾

每次拿到 PDF 時 ③b 重新解析 → 這次執行用的 start_page / end_page / anchor evidence
```

飛機照樣吃頁碼（PDF 工具最適合按頁讀），但那是 **anchor 對這份 PDF 的投影**，
不是跨 PDF 可保存、可比較的定位。⑤ 隨之升級成：

```
派工單記錄的 PDF fingerprint == 手上這份
且每個 start/end anchor 在該 PDF 唯一、依序、可解析
任一 anchor 缺失／重複歧義／順序倒置／範圍為空 → fail closed
```

**代價**（不是免費，但值得付）：
1. 標題不能只是人類可讀文字，要成為可解析的結構鍵 —— 重複標題、改字、全半形、
   換行、PDF 抽取錯字都會讓單純字串比對失效，每個 anchor 至少要帶
   occurrence／前後文片段／標題序列位置才能唯一化
2. 要建立 **anchor resolution failure 的正式狀態** —— 找不到、找到兩次、
   順序不單調，全部**不是「盡量猜一個頁碼」而是擋下派工**。
   以前靜默通過的文件會改成需要人工處理，⚠️ **而那正是應該浮出來的風險**

### Q2 ⑥ 的不變量：來源見證逐一閉合（不是 LLM 自我確認）

> 「標題真的在我讀的頁上」是**宣告，不是證據**。

```
① 決定性層從已鎖定的 PDF 範圍產出所有可辨識的結構見證
   （大題標題、題號、子題標記、詞語框標題、定義欄標題、關鍵文字錨點）
② 每個見證有穩定 ID、來源頁、文字指紋、角色 —— 不由 LLM 產生、不由 LLM 決定數量
③ LLM 產出每個欄位時，必須回填它覆蓋了哪些見證 ID
④ 決定性 verifier 驗三條：
     每個必需見證被覆蓋恰好一次
     沒有輸出引用不存在的見證
     沒有未解釋的見證遺留
```

核心不變量：**來源中所有應抽取見證 == 輸出中所有已對帳見證**

飛機少讀一頁時，該頁的題號或文字錨點沒被映射 → 派工直接失敗。
這不證明模型「真的讀過每一頁」，但**機械地證明它交出的資料沒有遺漏來源已辨識的結構** ——
對靜默截斷而言，這才是有效的不變量。

### Q3 內容忠實度：CI 拿不到原稿，就不要假裝 CI 在驗

切成兩個信任區：

| | 責任 |
|---|---|
| **Private fidelity runner**（能存取原稿） | 跑 `verbatim_gate`，產出 **attestation** |
| **CI**（拿不到原稿） | 不重跑比對，只驗 attestation 存在、且綁定正確的 hash |

attestation 至少綁：原稿 DOCX hash · 被抽取 PDF hash · yml/畫面資料 hash ·
gate 版本 · 通過結果與覆蓋摘要。

⇒ CI 的責任是「**沒有私有忠實度證明就不能進**」，
private runner 的責任才是「內容是否真的忠於原稿」。

> 如果連 private runner 都不能持有或讀取原稿，這條 gate 在架構上就是**不存在**，
> ⛔ 不能以 schema 綠燈替代。
