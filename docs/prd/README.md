# PRD 總覽（SOT 索引）

> 這份是所有功能 PRD 的**唯一入口**。要知道某個功能「規格在哪、做到哪、在哪個環境」，先看這張表。
> 規格本身以各 PRD 為準；狀態以本表為準，每次合併或上線後更新這裡。
> 最後更新：2026-11-13（依 git 紀錄與已合併 PR 整理）

### 狀態怎麼讀

- **正式環境**：已合進 `main` 並由 Deploy to Production 部署
- **只在 staging**：已合進 `staging`，還沒進 `main`
- **未開始／未合併**：只有 PRD、設計文件，或 PR 還開著
- 2026-11-12 的 release #4002 把當時 staging 全部合進 `main`（真 merge，含 9 個 migration），所以 2026-11-12 以前合進 staging 的功能都已在正式環境
- Hans 驗收以 issue 上的 `hans-verified` 標記為準；本表列到的遊戲化票目前都沒有這個標記

### 跨功能的共同規則（各 PRD 都適用）

- **老師控制班級功能**：`classrooms.feature_settings`（`pk_human`、跨班賽季、課堂搶答，預設都關）。AI PK 不受班級限制
- **孩子之間沒有互動管道**：真人對戰、組隊都不提供聊天或表情；對手隊只看到匿名「學生N」顯示名稱（#3677）
- **不抽卡、不花錢**；計分以答對為主，速度只用來決勝
- **劇情內容中立**：故事設定在「書中世界」；禁用字由劇情包驗證器擋（中華、中國、祖國、民族、我國、統一、收復、大一統、炎黃子孫）；反派抽象化
- **圖片**用 codex 產生，出圖 prompt 存在圖檔旁的 `_prompts.json`；程式碼不外包

### 待辦（不排進目前 MVP）

- 劇情包第二批：西遊記、封神榜、宇宙漫遊、台灣原住民族（需查證出處並請原住民族教育者審）
- 2D 劇情模式接進 PK／跨班賽季畫面

## 怎麼維護這份索引

1. 新增功能 PRD → 放進 `docs/prd/`，並在對應的節加一列
2. 功能合併進 staging、上線、或 Hans 驗收後 → 更新「狀態」與「環境」兩欄
3. 個別 PRD 開頭的「狀態」一行跟這裡不一致時，以這裡為準，並順手把那行改掉
