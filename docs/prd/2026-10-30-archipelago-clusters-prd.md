# PRD：群島模式（主題群島 ＋ 傳送門）

> 2026-10-30 · 父票 #3780 · 接在 `2026-10-26-reading-island-3d-prd.md` 之上（單課島那一層不動）
> 狀態：實作中。修改本檔前先在 §9 記一行

## 1. 要解決什麼

學生在「我的群島」看到的是 179 張卡片的清單，沒有「這是一片我在開拓的世界」的感覺。
外部參考作品（臺北施政島、投商資處未來島、HEART 政策島）都是**一張 3D 地圖、5–14 座六角小島互聯**，一眼就有世界感。

我們有 179 課，不能把 179 座全部互聯——太擠、看不清、手機跑不動。
Young 2026-10-30 定案：**依主題分成大群；每群是一張 3D 地圖、裡面十幾到三十座小島；群與群之間用傳送門往來。**

### 成功指標（上線後可量）

- 學生從遊戲區進入後，**10 秒內**看到自己所在年級的 3D 群島，已佔領的島一眼可辨
- 從群島點一座島 → 登島（進入那一課的單課島）≤ 2 次點擊
- 跨群（例：第 5 級 → 文言文）≤ 2 次點擊，有完整傳送動畫
- iPad（2020 以後）與 390 寬手機：群島場景 ≥ 30 fps、0 頁面錯誤

### 2.2 可切換分群方式（同一批島重新分群，進度共用）

**2026-10-31 訂正（Young：「那你島嶼就要依照學習能力三層做分群」）：預設分群改成「學習表現」**
（108 課綱學習能力三層之一），年級／文體／類別三個保留成可切換的選項，不是預設。

| 分群方式 | 欄位 | 群 |
|---|---|---|
| **學習表現（新預設）** | `lessonCurriculum.json` → `primary_indicator.code` | 19 個代碼，少於 4 課的併入同學習階段「第Ⅱ／Ⅲ／Ⅳ階段・綜合」群（見下方併群規則），共 14 群 |
| 學習內容 | `lessonCurriculum.json` → `learning_contents[0].code` 前綴 | Ad／Cb／Bc／Ab／Ba／Bd 共 6 群，全部 ≥4 課不需併群 |
| 核心素養 | `lessonCurriculum.json` → `core_competencies[0].general_item` | A2／B1／B2／B3／C1+C2 共 5 群（C2 併入 C1，見下方） |
| 年級 | `grade` | 如上 8 群 |
| 文體 | `genre`（正規化） | 說明文、記敘文（含記敘說理／記敘抒情／科學故事）、議論文（含論說文）、抒情文、文言文、應用文、其他（空值） |
| 類別 | `category` | 自然科學 Science、寓言故事 Fable、歷史人文 History、生活 Daily、其他（空值） |

**108 課綱三層資料來源**：`.claude/skills/lesson-curriculum-mapping` 產出的
`docs/design/reading-babies/lesson-indicators.json`（教授節點＋AI 逐課推論，**課綱分類
為草稿、未經老師審核**），由 `.claude/skills/lesson-curriculum-mapping/scripts/
build_archipelago_curriculum.py` 抽成精簡檔 `frontend/src/pages/student/archipelago/
data/lessonCurriculum.json`（只含三層代碼，不是整份 1.6MB 塞進前端）。HUD 分群切換旁
固定顯示一行小字「課綱分類為草稿，待老師審核」，不藏起來。

**併群規則**（不能讓一座群只有 1 座島）：
- **學習表現**：19 個代碼裡少於 4 課的全部併入同學習階段的「綜合」群；Ⅱ 階段的 4 個
  小代碼（5-Ⅱ-6／5-Ⅱ-4／5-Ⅱ-5／5-Ⅱ-9，合計 6 課）併成「第Ⅱ階段・綜合」；Ⅲ 階段
  2 個小代碼（5-Ⅲ-12／5-Ⅲ-9，合計 5 課）併完仍要再跨階段吸收 Ⅳ 階段唯一的小代碼
  （4-Ⅳ-3，2 課），一起變成「第Ⅲ／Ⅳ階段・綜合」（合計 7 課）——只在同階段合併仍
  不足 4 課時才跨階段，不動其他已經 ≥4 課的標準代碼群
- **核心素養**：C2（人際關係與團隊合作，僅 1 課）併入同面「C 社會參與」的 C1（道德
  實踐與公民意識，36 課），群名「道德實踐與人際合作（C1＋C2）」
- **學習內容**：6 個前綴全部 ≥4 課，不需併群
- 群名給學生看得懂的中文（例：「篇章：段落與結構（Ad）」），代碼放括號裡小字，不是
  只顯示裸代碼；查無對照資料的課一律歸「其他」群，不會從結果中消失

- 單群島數多時，拼塊陸地自動長大（見 §3.2），不拆群
- 分群方式記在網址 `?group=performance|content|competency|grade|genre|category`，
  重新整理不會跑掉

## 3. 群島場景（一群一張 3D 地圖）

### 3.1 視覺

- 風格對齊單課島：溫暖微縮模型、低多邊形、柔和陰影、淺藍海
- 每課一座**六角小島**；中央一座較大的**傳送門廣場島**
- 島上小景依課程類別換造型（科學＝圓頂／天文台、寓言＝樹屋／動物、歷史＝亭台、生活＝房舍），讓同群的島看起來不一樣

### 3.2 排列（2026-10-31 二次訂正：不規則群島＋相鄰互通、材料隨意）

Young 2026-10-31：「做出不規則群島的感覺，相鄰的島有一點互通的機制，但隨意材料」。取代前一版「整塊拼塊陸地」。

- **不規則群島**：島的大小、形狀都不同——有的 1 格、有的 2～3 格六角黏成的小島塊；邊緣不規則；島與島之間有寬窄不一的水道；整群看起來是自然散布的群島，不是幾何圖形、不是一圈一圈、不是一條線
- **相鄰才互通**：只有距離近的島之間有連接，遠的不連；不是每座都連，像真的群島一樣有的靠橋、有的獨立
- **連接材料隨意**：木棧橋、石板跳石、吊橋、淺灘沙洲、小船渡口……每一對相鄰島隨機挑一種（用固定種子，同一群每次打開長一樣）
- **連接只是好看，不限制操作**：點任何一座島都能直接選它，不必「走過去」（不做跟學習無關的操作）
- 傳送門廣場在群島中心附近，比其他島大、明顯
- 每座島是一個小景：1～2 棟建築＋樹＋小吉祥物，側面露出土層
- 名牌：已佔領、探索中、鏡頭焦點最近 8 座常駐顯示課名；其餘島顯示狀態色小圓點，hover／點一下展開名牌；名牌兩兩不重疊（2026-10-31 team-lead：36 島大群全部常駐會擠成一團）
- hover／點一下時那座島浮起、加亮、名牌強調色
- 位置、島形、連接、材料全部是決定性的純函式，有單元測試（同輸入同結果；每座島至少有一個鄰居或明確標為獨立島；連接只出現在距離門檻內）

### 3.3 三種島的狀態（沿用既有 `islandStatus()`，不重新判定）

| 狀態 | 長相 | 標籤 |
|---|---|---|
| 已佔領 | 綠意滿、插旗、建築亮燈、輕微發光 | 「已佔領」 |
| 探索中 | 半綠、旁邊浮著進度環 N/M 站 | 「探索中 N/M」 |
| 尚未探索 | 沙洲灰調、薄霧覆蓋 | 「尚未探索」 |

### 3.4 操作

- 拖曳旋轉、滾輪／雙指縮放、自動限制在群的範圍內
- 點一座島 → 鏡頭飛過去 → 左側出現島卡：課名、年級、文體、狀態、進度條、**「登島」**按鈕
- 「登島」→ `/lab/island/:storyId?from=archipelago&group=…&cluster=…`；單課島的「回群島」回到原群、鏡頭停在剛那座島
- 右側面板：本群島清單（狀態點＋課名），點清單項 = 點那座島；上方有搜尋框
- 頂部 HUD：群名、本群進度「已佔領 x / y」、分群方式切換、「清單模式」切換、文字寶貝入口

## 4. 傳送門

- 傳送門廣場上，**當前分群方式的其他每一群各一座門**（年級模式＝7 座），門上掛群名與該群佔領進度
- 點門 → 鏡頭推入門內 → 白光過場 0.6 秒 → 載入目標群 → 鏡頭從目標群的傳送門廣場拉出
- 右側面板頂部另有「群島導覽」下拉，可直接跳群（同一套傳送過場）
- 支援減少動態偏好（`prefers-reduced-motion`）：過場改成淡入淡出

## 5. 進入點與預設落點

- 遊戲區「島嶼探索」卡 → `/student/archipelago`
- 預設落在：**最近一次學習的那一課所在的群**；沒有學習紀錄則落在第 4 級
- 網址 `?cluster=` 有值時以網址為準

## 6. 降級與無障礙

- WebGL 無法建立 → 自動切到現有清單模式（不顯示錯誤頁）
- 清單模式永遠可切換，內容與 3D 同一份資料
- 島與門都可鍵盤 Tab 選取、Enter 進入；畫面上有 aria-label
- 手機（< 640 寬）：右側面板改成底部抽屜

## 7. 資料與效能

- 只打兩支既有 API 各一次：`/api/stories?page_size=300`、`/api/learning/students/{id}/progress`（沿用既有 `buildArchipelago()` 與 `stories.length === total` 檢查）
- **不新增後端、不加 migration**
- 同類造型用 InstancedMesh；換群時釋放上一群的幾何與材質（沿用 `disposeObjectTree`）
- 每座島都看得到標記（名牌或狀態色圓點），名字可在 hover 時看到（§3.2）

## 8. 驗收（Given / When / Then）

1. Given 學生小明最近學過一課，When 從遊戲區點「島嶼探索」，Then 落在**該課在「學習表現」分群下所屬的群**（2026-10-31 改預設；舊版驗收是「落在第 5 級群島」，那是年級模式才有的落點，年級模式仍可切換驗證）
2. Given 小明在任一群，When 看已佔領的島，Then 它有旗子與亮燈，標籤寫「已佔領」；探索中的島顯示「探索中 N/M」，數字與 `/progress` 一致
3. Given 在第 5 級群島（切到依年級），When 點傳送門廣場上「古文群島」的門，Then 播放傳送過場並進入古文群島，網址變成 `cluster=文言文`
4. Given 在任一群，When 點一座島再按「登島」，Then 進入該課單課島；按「回群島」回到同一群
5. Given 切換分群方式為「文體」，Then 群數與每群課數等於 API 依 `genre` 正規化分組的結果，179 課每課剛好出現一次
6. Given 390 寬手機，Then 無水平捲動、底部抽屜可開合、0 頁面錯誤
7. Given WebGL 不可用，Then 自動顯示清單模式
8. 所有群加總的島數 = API `total`（179），不重複不遺漏——對六種分群方式（學習表現／學習內容／核心素養／年級／文體／類別）各驗一次，且任一群都不少於 4 座島

## 8.5 主題皮膚（骨架不變、換長相）

Young 2026-10-30：底層模式不變，可以換成海底世界、星際、異世界、幻想神話大陸、天空島等主題。

**做法：場景程式只認一份「皮膚設定」，不准把海、島、顏色寫死在場景裡。**

| 骨架（所有主題共用，不准因主題而改） | 皮膚（每個主題一份設定） |
|---|---|
| 分群、拼塊座標、三種狀態判定 | 底面：海面／深海／星空／雲海／大地 |
| 點島 → 島卡 → 登島 | 「島」的造型：六角島／珊瑚礁／小行星／浮空岩／大陸板塊 |
| 傳送門邏輯與過場時序 | 傳送門造型：石門／漩渦／星門／彩虹橋 |
| 進度、清單、HUD、無障礙 | 連接物：棧橋／海流／光束／鎖鏈 |
| 資料與 API | 色票、光線、霧、粒子（泡泡／星塵／雲絮）、背景音 |
| | 三種狀態的視覺：已佔領＝插旗／發光珊瑚／點亮星球… |

- 皮膚是純設定檔（`themes/<id>.ts`），**新增主題 = 新增一個檔案**，不動場景程式
- 有測試鎖住：每個主題設定都必須提供上表右欄每一項，少一項就紅
- 學生可在 HUD 切換主題，記在學生偏好（前端 localStorage，不加後端）

**本輪交付**：骨架＋皮膚設定介面＋2 個主題（海島＝預設、天空島）。
天空島最接近現有素材（浮空島＋雲海），用來證明「換皮不動骨架」真的成立。
其餘主題（海底、星際、異世界、神話大陸）排下一輪，每個主題只交一份設定檔＋造型。

⚠️ **不做海賊王**：海賊王的世界觀、地名、角色是集英社／尾田榮一郎的著作權，放進產品＝侵權。
可以做「海賊冒險風」原創主題（自己取名的島、自己的船與旗），不用任何原作名稱與造型。

## 9. 不做（這一輪）

- 群與群的島之間跨群互聯（Young 明令：不要 179 座互聯）
- 多人同時在地圖上看到彼此
- 新的後端欄位或資料表
- 單課島內部的任何改動（除了「回群島」按鈕帶回原群）
