缺口 0：I-6 假綠歷史（#2273 postmortem）

Admin 重點表 manifest 與 runtime story_structure_table 曾出現不同步（manifest 顯示通過但學生端看到舊資料）。根因：同 PR 沒有 rebuild manifest + verify。I-6 不變式現在明確列入 merge-blocking L2 — 同一 PR 改 keypoints.yml 必須同時執行 keypoints_manifest_verify.py，否則視為假綠。

缺口 1：llm_generated 課文需人工驗證

151 課全通 L1-L3 gates，但 tier=llm_generated 的課文由 Gemini 生成內容，尚無人工抽驗流程確保品質一致性。建議：逐課核對 keypoints 是否與紙本學習單吻合。

缺口 2：StoryStructureLabPage 僅後台可見

重點表 UI（StoryStructureLabPage.tsx）目前只在 admin 後台路由可見，尚未整合進學生正式學習流程（7 步驟 stepper）。7/1 deadline 前需確認整合範圍。

設計鐵律

  • 每格現況必須掛可點的證明連結（PR / commit / curl output）
  • 無證明 → 標 未驗證，不得宣稱完成
  • tier=llm_generated 課文需附人工複核紀錄才算完整
