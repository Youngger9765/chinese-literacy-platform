# #2735 — 從教師版 DOCX 讀回老師打的 ☑

## 為什麼有這個目錄

#2555 把老師的勾（`<w:sym w:font="Wingdings" w:char="F0FE"/>`）正規化成 `□`，
好讓學生看不出哪個選項被勾。但**抽取器原本就靠那個洩漏在判答案**
（`parse_option_line` 的「沒有框的那個 = 答案」），所以補完框之後 312 題的答案變了。

原票說「A 和 B 都是在猜」。**那個前提不成立** —— 真值還在 L2 的教師版原稿裡。

## 查證結果（2026-08-21）

```
對得上平台的課      74 / 152（49%）—— 6、7 年級與 G5 後段的原稿不在 L2
```

## 我量錯過兩次，別重踩

1. 三方比對（舊/新/真值）得到 `舊 0% / 新 0.2%`，看起來像兩邊都爛 ——
   **兩個 bug**：`answer:` 存的是索引（`A`/`2`）不是文字；`v3` 是 8/18 才建的、
   在 `d1692687~1` 之後，所以「舊答案」那側從頭到尾是空的。兩側都空，兩個 0 是必然。
2. 整體命中率 29%（158/545）**不能拿來說「71% 的答案是錯的」** ——
   G5-L15 有 19 個 ☑ 但我只解出 8 個答案，落差主要來自**我沒把所有題型解出來**
   （☑ 也出現在自我檢核表這類非選擇題處）。要下那個結論得逐題對齊。
