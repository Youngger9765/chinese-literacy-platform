## 📋 核心學習模組

### 1. 朗讀練習模組

**功能描述**：
- STT (Speech-to-Text) 語音辨識
- AI 評分（準確率、語速、流暢度）
- 錯誤分析（跳字、加字、讀錯）

**資料結構**：
```sql
reading_sessions:
  - session_id
  - student_id
  - course_node_id  -- 關聯到課程節點
  - audio_url
  - transcript (STT 結果)
  - wer (字錯誤率)
  - accuracy
  - speed (字/分鐘)
  - fluency_score
  - ai_feedback TEXT
  - created_at

reading_errors:
  - error_id
  - session_id
  - error_type (skip | insert | substitute)
  - position
  - expected_word
  - actual_word
```

---

### 2. 生字詞學習模組

**功能描述**：
- 部件拆解教學（閱讀科學教學法）
- 筆順動畫（方大哥 9,606 字資料）
- 生字測驗

**資料結構**：
```sql
words:
  - word_id
  - word VARCHAR(10)
  - bopomofo
  - tone
  - radical
  - components JSONB
  - stroke_order_json JSONB
  - definition

word_learning_sessions:
  - session_id
  - student_id
  - word_id
  - activity_type (view | write | quiz)
  - quiz_score
  - created_at
```

---

### 3. 閱讀理解測驗

**功能描述**：
- 選擇題、問答題
- AI 批改開放式問答
- 理解能力評估

**資料結構**：
```sql
comprehension_questions:
  - question_id
  - course_node_id
  - question_type (multiple_choice | short_answer | essay)
  - question_text
  - correct_answer (nullable for essay)
  - rubric JSONB

student_answers:
  - answer_id
  - student_id
  - question_id
  - answer_text
  - is_correct
  - score
  - ai_feedback
  - created_at
```

---

### 4. 蘇格拉底對話（Phase 3）

**功能描述**：
- AI 引導式對話
- 開放式問答
- 思考能力評估

**資料結構**：
```sql
socratic_dialogues:
  - dialogue_id
  - student_id
  - course_node_id
  - conversation JSONB
  - comprehension_score
  - turn_count
  - created_at
```

## 🎯 學習流程設計

### 典型學習路徑

```
1. 學生打開課程
   ↓
2. 選擇學習模組
   ↓
3. 完成學習活動
   ↓
4. AI 即時批改
   ↓
5. 錯誤分析 → 推薦補救
   ↓
6. 記錄學習活動
```

## 📊 API 設計

### 朗讀練習 API

```python
# 提交朗讀音訊
POST /api/reading-sessions
{
  "student_id": "uuid",
  "course_node_id": "uuid",
  "audio_file": "base64_or_url"
}

# 回應
{
  "session_id": "uuid",
  "transcript": "我有一個溫暖的家",
  "accuracy": 0.95,
  "speed": 85.5,
  "wer": 0.05,
  "fluency_score": 88,
  "errors": [
    {"type": "skip", "position": 5, "expected": "溫暖"}
  ],
  "ai_feedback": "朗讀流暢，但『溫暖』跳字了，建議重讀一次。"
}
```
