## 本課學習策略（`目標策略`）—— 課程簡介頁那個黃框

⚠️ **資料不落在 `intro_guide.yml`，落在 `metadata.yml` 的 `strategy` / `strategy_explained`。**
那兩個欄位早就存在、也早就接到 API（`lesson_indexes.py` 的 `reading_strategy`）。
規格寫在這裡是因為它是**課程簡介頁**顯示的東西，但資料只准有一個家 ——
再開第二個家就是下一次 v2/v3 撞車。

### 兩個來源都要參考，讓 LLM 整合

策略有兩份紀錄，**都不完整，而且不是同一批課**：

| 來源 | 位置 | 有值的課數 |
|---|---|---|
| 學習單 | 第一頁「目標策略：X──Y」 | 129 |
| 總表 | `curriculum-index.json`「閱讀聚光燈策略──教材目標策略（學習單第一頁右上方）」 | 129 |
| **聯集** | | **160 / 175** |

owner 2026-08-23：「**應該都要參考，然後 LLM 判斷怎麼整合**」。

兩份不一樣時多半是**細緻度不同**，不是互相矛盾：

```
L0016  學習單「推論策略」          總表「推論策略──推論代名詞」
L0018  學習單「認識句型」          總表「認識句型──遞進複句」
L0014  學習單「推論文章主旨」      總表「找出文章主旨」
```

兩份原始值都寫進 `metadata.strategy_sources`，將來有人問「這句依據什麼」，
答案要在檔案裡，不是在某次批次的終端機捲軸裡。

### 🔴 join 之前先斷言鍵是唯一的

`curriculum-index.json` 裡有**四張 sheet**（影片連結-新 158 / 總表 148 /
注意課次安排 69 / 文言文 10），課名會跨 sheet 重複。只有 `總表` 與 `文言文`
帶策略欄。

⛔ **join 之前一定要先過唯一性斷言**，不唯一就 raise，不要「取第一筆」繼續。
一個鍵不唯一的 join 會**安靜地對到錯的那一列，而值看起來完全正常**。

2026-08-23 同一天踩了兩次：

| 錯法 | 症狀 | 怎麼發現的 |
|---|---|---|
| 用 `catalog_slot`→`新課次` 對 | 每一課都拿到一個像真的策略字串 | 加「總表那列的課名 == 這課標題」對照：**相符只有 2/175** |
| 用課名對但沒濾 sheet | 對到「影片連結-新」那張（沒有策略欄）→ 誤報「總表只有 24 課」 | 濾成 `總表`+`文言文` 後：158 列 / 158 相異課名 / **0 重複** |

`load_master_sheet()` 已經把這條做成硬斷言。**不要為了讓它跑過而改成取第一筆。**

### 原稿怎麼存

拆成**相鄰兩段**，接起來才完整：

```
[0] 目標策略：摘要策略──
[1] 找小主題和重要細節
```

規則：找到 `^目標策略[：:]` 的段落；若它以破折號結尾，下一段就是尾巴
（尾巴要 ≤30 字且不是另一個 `目標策略`，否則只取前半）。實測抽得到 **129 / 175**，
96 種相異策略，中位數 13 字。抽不到的 46 課是**學習單真的沒印**，⛔ 不要憑空生。

⚠️ 逐字一律回 DOCX 的 `<w:t>` 流取。`pdftotext -layout` 會為了排版折行，
折點落在標點上就把標點吃掉 —— 讀起來完全通順、schema 過、沒有任何症狀。

### 只有名稱不夠

「摘要策略──找小主題和重要細節」是一個**名稱**，不是說明。四年級學生看不出要練什麼。
Owner：「就這麼短嗎？」「要善用 LLM 去表達啊」

`strategy_explained` 用 LLM 展開成 2–3 句，回答學生心裡的三件事：
這課要練什麼（白話）／為什麼**這篇**適合練它（要扣住具體內容，不能泛泛而談）／讀的時候怎麼做。
用「你」稱呼、繁體台灣用語、句尾不加句號。

**批次預生成，不即時呼叫**：一年不會變、可人工校對、runtime 零成本，
而且每一課能單獨重跑。即時呼叫每次講法都不一樣，也沒人看得到它講錯什麼。

### 房規交給決定性後處理，不交給 prompt

句號那條（中文除正式文件外不加句號）prompt 講了模型還是會忘。
`tidy()` 直接把行尾句號 strip 掉。能用一行 replace 解決的不要交給機率。

長度超標、句中仍有句號、出現「本文／本課／筆者」→ **標記但不擋寫入**。
這是機率性產出，完成的判準是「流程對、出錯知道在哪、能單獨修」，不是每課完美。

## 收尾自驗

```bash
python3 -c "
import json,yaml,sys
s=json.load(open('specs/modules/schemas/intro_guide.schema.json'))
b=yaml.safe_load(open('\$OUT'))['intro_guide']
extra=set(b)-set(s['properties']); missing=set(s['required'])-set(b)
print('未宣告欄位:', extra or '無'); print('缺必填:', missing or '無')
sys.exit(1 if (extra or missing) else 0)"
```
